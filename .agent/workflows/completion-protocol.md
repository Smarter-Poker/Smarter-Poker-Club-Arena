# Delivery and verification entry point

Read root `AGENTS.md`, `AGENT-PLAYBOOK.md`, `docs/agent-policy/REFERENCE-INDEX.md`, and `PUBLISHING.md`. These maintained sources replace the former duplicate procedure here. Complete the authorized scope through actual required checks, protected merge, the approved provider and live proof. Recover failed operations immediately under the operating law; preserve unknown outcomes and required maintenance safeguards.

Use an owned worktree, explicit staged paths, ordinary hooks and configured authenticated tools. Do not use shared-clone push scripts, API file writes to bypass hooks, blanket conflict resolution, dummy deployment commits, retired autopilot, watchers or local/custom publishers. Never source `.env` values.

For database work, read the applicable migration and financial rules, qualify the exact transition and verify installed state. Compatibility determines installation order; neither “SQL always last” nor “CI applies it” is a valid universal rule. Never replay installed migrations or weaken the database maintenance boundary.
