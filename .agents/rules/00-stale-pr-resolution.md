# Resolve an assigned stale PR

Follow root `AGENTS.md` and `PUBLISHING.md`. Compare the assigned PR with current main and preserve all intended work. Close an obsolete PR only within your assigned authority after proving its complete replacement or inclusion. Do not close another task’s PR because of age or a newer commit. Repair genuine conflicts on the owned branch, run affected required checks and complete the protected route. No numbered queue or global coordinator is required.
