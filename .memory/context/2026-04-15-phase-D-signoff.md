## Areas that exceed PokerBros baseline

- **Distribution clawback (10-min window)** — `AgentService.clawbackDistribution` lets a super-agent reverse a chip distribution within 10 minutes of sending it. PokerBros has no clawback.
- **Race-safe agent mint** (`20260311_fix_mint_agent_race_conditions.sql`) — protects against double-mint when two super-agent admins click "send" simultaneously.
- **Dynamic club levels** (`20260322_dynamic_club_levels.sql`) — auto-promotes clubs based on volume + active members.
- **Rake waterfall as RPC chain** with treasury credit fix (`20260312_fix_rake_treasury_credit.sql`) — atomic per-hand attribution to treasury → club → agent → player rakeback bucket. PokerBros runs this server-side but exposes no audit trail; we expose `AdminReports.tsx` end-to-end.
- **Union admin role separation** with `isUnionAdmin` guard — distinct from club admin (PokerBros conflates them).
- **Public discovery + nearby clubs** — `ClubsService.discoverNearbyClubs` ranks by geo proximity; PokerBros only supports invite-by-code.

5. **Rakeback cashout** — accumulate rakeback; cashout via `cashout_rakeback` RPC; verify `rakeback_periods.cashed_out_at` stamped.
6. **Settlement period close** — trigger weekly settlement; verify `agent_settlements` row created with correct totals.
