# Club Arena Visual Composition Registry

This registry prevents adjacent Club Arena surfaces from converging on the same generated-image composition. A new visual must name its subject, camera, dominant silhouette, light source, palette, and interaction purpose before it ships.

| Surface                  | Asset                                                   | Composition                                                                                                                                                                                                    | Interaction purpose                                                                 | Reuse rule                                                                                                                                                |
| ------------------------ | ------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Players / Player Command | `public/images/club-members/roster-ledger-desk-v2.webp` | Physical pit-manager ledger photographed obliquely across a dark operations desk; ledger spine and stamped paper create the dominant horizontal silhouette; cool practical light with restrained gold hardware | Establishes the roster as an operating ledger before the live HTML directory begins | Keep only on roster/member-command surfaces. Do not reuse the desk, ledger, camera angle, or stamped-paper silhouette on another Club Arena card or hero. |

## Phase-three decision

The 2026-08-30 roster phase intentionally introduced no generated image. Its new visual identity comes from the sticky pit-tape control console, machined filter rail, selected-player strip, and recycled access plates. This keeps the existing accepted ledger hero while directly addressing repeated-image fatigue.

## Required variation axes for the next Club Arena visual

A future image must differ from the Players composition on at least four of these six axes:

- subject matter;
- camera height and angle;
- dominant silhouette;
- primary light direction;
- spatial depth;
- narrative action.

Changing only colour, signage, or a central emblem does not count as a new composition.
