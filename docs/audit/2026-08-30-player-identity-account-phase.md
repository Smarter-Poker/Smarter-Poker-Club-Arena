## Duplicate and low-value findings

- Profile-mounted `DailyBonusWheel` duplicated the canonical claim flow on `/bonuses` (and a promotion surface). Removed from profile; `/bonuses` is now the explicit destination.
- Profile-mounted `GamificationLeaderboard` duplicated `/leaderboard`. Removed from profile.
- Profile-mounted `PromotionsList` duplicated `/promotions`. Removed from profile.
- Profile-mounted Performance Trends, Player Style Radar, and Stake Comparison duplicated the much deeper `/stats` workspace and added independent queries/realtime listeners. Removed from profile.
- The empty Settings **Gameplay** section was a low-value dead surface left behind after its nonfunctional toggles had correctly been removed. The route alias now resolves to Table & Display.
- Profile transaction history overlapped `/transactions`. It is now a ten-row identity preview with a full-history handoff.
- Public player profiles inherited an own-account rail because `/profile/:userId` matched `/profile` by prefix. That misleading rail is no longer returned.
- Public profile and profile-editor styles used broad global selectors such as `.stat-card`, `.achievement-card`, and `.cancel-btn`. The redesigned rules are scoped under their page/dialog roots.

## Missing surfaces assessed

No new top-level account route is required to complete the current live contracts. A future “active sessions/devices” security page would require a real backend session-management contract; this phase does not invent one. Missing addressability was solved with retained query-based subroutes rather than multiplying pages.

## Route change ledger

No route was deleted and no redirect was required.

- Added addressable nested states: `/profile?tab=achievements`, `/profile?tab=history`, `/profile?tab=social`, `/settings?tab=table`, `/settings?tab=data`.
- Preserved compatibility aliases: `/settings?tab=appearance`, `display`, `gameplay`, `language`, `security`, and `account`.
- Renamed UI only: Stats → Snapshot, History → Activity, Friends → Network, Display → Table & Display, Notifications section → Alerts, Account → Identity Security, Danger Zone → Account Data & Closure.
- Merged the empty Gameplay surface into Table & Display.
- Removed duplicate profile embeds and linked to retained routes: `/bonuses`, `/leaderboard`, `/promotions`, `/stats`, `/achievements`, `/transactions`.
- Unified the global profile button on `/profile` instead of `/hub/profile`.

## Preserved contracts

- No Supabase table, RPC, policy, auth, or realtime channel contract was renamed.
- Profile caching, retry behavior, visibility refresh, Master Bus events, diamond/streak updates, and lazy chart loading remain active.
- Settings bridge/store ownership, table live updates, SoundService gate, real notification preference columns, VAPID subscription flow, email/password updates, MFA enrollment, export, delete, and confirmation handlers remain active.
- Notification feed routing remains server-resolved; the page still does not introduce a second notification routing table.
- Friendship, messaging compose deep link, block/unblock, public status, table navigation, QR, and sharing behaviors remain active.
- Public friendship state now treats the live reciprocal accepted-row pair as one relationship instead of incorrectly requiring a single database row.
