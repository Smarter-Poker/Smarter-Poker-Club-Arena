## A. Every writer of every balance store

Method: `pg_proc` scan (schema `public`, plpgsql/sql) for `UPDATE <table> ... SET <col> =` inside one
statement, or `INSERT INTO <table>(... <col> ...)`; for `table_seats` additionally any `UPDATE ... SET
left_at =`, `DELETE FROM table_seats`, `INSERT INTO table_seats` (an exit or a seat creation moves the
live-stack balance without touching `stack`). Functions that only CALL a writer are listed as callers
under the writer. Columns: **Reg** = `ca_money_rpc_registry.status` (`-` = not registered);
**Decl** = stamps `app.ledger_category` or calls `fn_ca_declare_ledger` (`skip` = uses
`ledger_autoskip_*` to silence the autoledger for at least one table); **Key** = has an idempotency
key / ON CONFLICT guard in the body; **ACL** = roles with EXECUTE (all listed are SECURITY DEFINER
unless marked `invoker`); **Class**: STANDARD = the function 3.2 names for that movement; LEGACY = a
second way to do a movement the standard assigns elsewhere; PLUMBING = primitive/trigger/repair arm
used _under_ a standard path; PRODUCT = live cashier/agent/union product path the standard does not
name (not legacy, not yet standardised).
