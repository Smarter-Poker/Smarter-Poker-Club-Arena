Every present durationMinutes, duration_minutes or duration term must be a finite positive JSON number; minutes and seconds must describe the same duration at database microsecond precision. Missing, null, boolean, string, negative, zero, object, array and contradictory terms refuse. They cannot silently select a fallback or another alias.
