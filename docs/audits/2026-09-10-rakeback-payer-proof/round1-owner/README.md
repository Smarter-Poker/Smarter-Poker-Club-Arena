# Prospective Funding Candidate Checkpoint

This directory is an unactivated accounting candidate. No production migration, engine restart or browser publication is performed by these proofs.

The actual-money fixture loads 122 tables, 231 functions and 175 enabled triggers, with no missing foreign tables. It composes the captured accepted-hand and bank owners, the real treasury credit/debit cores, source capacity, player transfers and their financial guards. Current actual timestamps prove open-window refusal. Closed-calendar cases use local BEFORE INSERT timestamp fixtures through unchanged owners; those cases do not establish historical production source ownership.

The bounded Round1 proof has 11 groups. It covers compatible Pacific-window fractional carry, exact request replay, older-cutoff highwater, complete public-row rollback, linked-money immutability and direct-bank capacity without another treasury credit. The player proof has 15 distinct groups, including 100 sequential penny sources at 15%, exact cross-week source slices, actual allocation capacity, no cross-payer/Union borrowing, departure/deactivation and full composed rollback.

The version2 claim probe first repeats those 15 player groups, then runs 25 additional API groups. Count the repeated base only once. It uses the real getter and payment DTO, tests zero/paid receipt recovery, account and club binding, malformed/late scope checks, capability withdrawal, two funded races observed at the shared club advisory lock, final request rollback and exact read reconciliation. The late-club getter substitution is a native fault fixture; the two funded claim races execute the unchanged actual claim wrapper.

The API returns exact decimal strings for earning and source consumption, separately from whole-cent payment receipts. Source liabilities remain visible before banking, without fabricated pool UUIDs. Compatible closed UTC weeks carry within the original funding scope and captured payer. The real capability table remains empty outside an explicitly synthetic native witness. Current legacy function definitions in that synthetic witness are metadata only: they are not executed or represented as excluded.

Run the base proof with `bash round1-owner/run-local.sh`. Set `ROUND1_PROBE` to the absolute player-native-probe.py or claim-native-probe.py path to run those compositions. Every runner creates a private Unix-socket PostgreSQL cluster. Exact source hashes and actual response hashes accompany each proof.

The older 31-group payer/wrapper proof and 10-group outer control proof remain reproducible. The older per-week payment model is superseded by this cumulative candidate. The outer proof uses synthetic Round1/2/3 effects; it does not certify a full actual Union cascade.
