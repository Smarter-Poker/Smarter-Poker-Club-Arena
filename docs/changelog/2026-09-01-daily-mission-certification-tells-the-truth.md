# Daily Mission Certification Tells The Truth

The production certification proved that Daily Missions Realtime was restored,
then reported the next unrelated assertion as if no revision frame had arrived.
Its own captured frame list showed the expected revision update.

The catch-all event returns only mission rows advanced by that event. Earlier
certified reroll and freeze actions can already complete one assigned contract,
so nine returned rows can coexist with all ten assigned missions being complete.
The certification now treats the database's complete assigned set as the
authoritative completion proof.

Only the frame-specific wait is wrapped by the frame-specific diagnostic. Any
economy, completion, cursor, or UI failure now retains its real assertion and
stack trace.

This is test-only release infrastructure. It does not update any Club Bank,
Deep Stack Society membership, horse funding, player chip, wallet, or balance
row.
