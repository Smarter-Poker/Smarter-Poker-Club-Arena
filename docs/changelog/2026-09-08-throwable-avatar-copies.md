# Throwable performances can act on avatar copies

Anvil, ghost and UFO previously lacked their bespoke moving performances. The new rigs add the drop/flatten/pop, double cold pass, and tractor-beam abduction sequences with premium atlas artwork.

The player captures an optional read-only image or visible initial from the target seat in its own table. Copy-based rigs explicitly opt in; other throws do no canvas readback. No real seat DOM is changed, and missing or tainted sources degrade safely. The shared darkroom includes a visible initial fixture for copy effects.

Verification: full TypeScript and 77 focused tests passed; 29 browser captures and 45 normalized speed samples passed, with no page errors or reduced-motion animations. Existing licensed cues cover the mechanics; dedicated sound acceptance remains pending. The legacy artwork readiness test now uses the still-unrigged eight ball because anvil correctly loads an atlas.
