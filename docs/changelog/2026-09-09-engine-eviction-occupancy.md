# Engine eviction owns its original occupancy

evictExpiredSitOuts previously relied on its current call sites being between hands, checked only all-in players, and looked up the current seat after asynchronous eligibility reads. The engine now holds the shared seat boundary through settlement waiting, eligibility and cashout, retains the original candidate occupancy, excludes every live-hand participant including folded players, and refuses cleanup of a replacement. It rechecks current sit-out/away/abandoned eligibility before payment without counting another orbit, so a resumed player is not evicted from an old eligibility result.
