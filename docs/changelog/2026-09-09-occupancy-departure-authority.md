# Occupancy departure authority (unpublished Phase 2 work)

Deferred cash and tournament departure now confirm an engine-authorized database request for the original occupancy. The transaction stores forced authority with its seat flags, so restart cannot convert a forced exit into a voluntary one or apply the old request to a new seat.

Pending and clock-held paths retain occupancy through cashout/refusal cleanup. The canonical transaction owns player-count updates; an unlocked second recount has been removed. Administrative TableService kicks now enter the engine boundary, and ambiguous success envelopes are rejected.

Validated with 17,302 client tests, 7,806 server tests, 52 separately run isolated PostgreSQL tests and both type checks. This is not Phase 2 acceptance. Admin retry identity, indirect SQL callers, legacy retirement, deployment compatibility, browser acceptance and the remaining Phase 2 audit are still open. The migration has not been applied and the branch has not been published.
