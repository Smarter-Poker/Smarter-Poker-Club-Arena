# Heads-Up Native Funding Proof

The existing registration funding rehearsal now exercises the paid Heads-Up
seat, lease-bound launch and prestart refund routes together. Sixteen groups
cover NLH and PLO4 at 300 and 1,000 starting chips, exactly two seats, repeated
and competing seat requests, physical seat revival, observed lock overlaps,
and failures at the final seat, refund receipt and launch receipt writes.

The fixture imports 94 selected installed financial and seat proof triggers
and verifies 120 captured function bodies unchanged in each case. A read-only
production refresh also confirmed those bodies plus the current wallet debit
and club resolver (122 witnesses) and all 94 trigger definitions and enabled
states at 12:38–12:40 UTC on September 10. Auth and realtime delivery remain
synthetic. No production money, schema or source function changed.

The recovered full psql runner passed 53 groups. A final run through the pinned
Node PostgreSQL client passed all 16 Heads-Up groups after rollback and replay
snapshots were expanded to every public fixture table, including auxiliary
escrow journals and alert/support records. Each concurrency assertion observes
a real blocked contender while the first actual RPC transaction remains open.

The existing chip journal CI rehearsal invokes the default runner, so these
cases remain in its normal path. Exact commands, results, catalog witnesses,
file hashes and limits are in
`docs/audits/2026-09-10-heads-up-native-funding-evidence.json`.

This is bounded database proof. UI, engine/dealer execution, RLS, HTTP grants,
live maintenance, Union accounting, Diamonds, guarantees and historical records
still require their own verification. It does not complete the wider audit.
