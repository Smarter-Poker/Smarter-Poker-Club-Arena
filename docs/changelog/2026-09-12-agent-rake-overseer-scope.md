# Agent rake reads follow the overseer's club access

An overseer requesting an agent downline without a club filter could receive rake data from unrelated clubs. Derive the overseer fallback's allowed clubs from the requested active root and apply that scope to both the root and recursive children. Authorized rows retain the existing rake calculation; self, ancestor, explicit club admin and service alternatives retain their existing behavior.

The migration refuses unexpected definition or authority metadata, checks each transformation, preserves signature/owner/grants/settings, verifies the result and supports an exact repeat. Independent review 0063 accepted the SQL candidate and its portable CI package. The PostgreSQL 17 probe has 37 checks across 25 role cases, including the original leak, roots spanning clubs, a foreign-club recursive child, seven current helper fingerprints, drift refusal and unchanged fixture data.
