# Original Movement and Retry Authority

Tournament live-source moves require the current owned engine and a physical park boundary. If a pending move has no local engine, recovery can acknowledge only an exact already-committed receipt through the existing read-only resolver. Missing engine maps alone do not authorize a fresh move; fresh cold-source and one-player recovery remain open.

Cash and tournament lease renewal each retain at most one unresolved heartbeat transport. Deadline expiry releases the local caller and revokes the old result authority while the other scope continues. Shutdown uses the same bounded scopes. The remote request is not cancelled and can still renew its original database generation.

Qualified canonical rollback responses retry within the existing captured hand-history request and total attempt budget. The mutable outer settlement callback is not replayed. Original lease and hand custody, unknown-response handling, completion requirements and the final unproved-hand fence remain. Unqualified legacy rollback wording is not newly authorized.

Repository regressions cover retained transports, late replies, shutdown scope execution, immutable retry payloads and receipt/custody boundaries. Local tests and source review do not certify native funded behavior or a production release.
