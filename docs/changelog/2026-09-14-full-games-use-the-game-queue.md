# Full Must-Move games use their game queue

A full game card and its detail panel previously called the standalone table waiting-list door for Main 1. Both now use the existing game-join flow, which reserves the server-selected destination or joins the game queue that drives feeder opening. Manual tables and cancellation retain their existing paths.

The common join service rejects unconfirmed or malformed responses before any caller can navigate or show success. A pending club-page join belongs to its initiating club/account opening; late replies after retirement cannot navigate or notify, and a repeated tap sends one request.
