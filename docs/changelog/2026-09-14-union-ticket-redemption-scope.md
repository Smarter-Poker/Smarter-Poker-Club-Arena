# Ticket redemption follows the club scope used by issuance

Satellite settlement and the shared club resolver already accept a union event's host club or a listed member club. Three ticket functions instead required both host-club equality and a union_clubs row. Member-club tickets failed the first condition; host tickets failed the second because the union host deliberately has no self-membership row.

The exact installed ticket selector, horse hint reader and beneficiary admission now use the existing issuance scope. Standalone events still require their own club. Union events accept their host or a current member club, with active holder membership and exact shared-resolver agreement still required. Direct tickets remain bound to their original target; returned tickets retain their separate refund-entitlement rules. The migration changes only those predicates and preserves all other function bytes, ownership, grants, execution metadata, issue proof, entry limits and financial operations.
