# Independent PKO heads below a later watermark

An accepted knockout could remain unpaid after a later hand paid an unrelated head at the same table, or added a separate carry to the same collector. The watermark helper treated either relationship as a head consumption dependency. The payout split actually depends on the eliminated player's head; two independent incoming carries do not change each other's split.

The additive migration changes only `fn_pko_watermark_admission_status_v1`. After validating the existing accepted hand identity, exact claimants and complete settled payout marker, it permits independent transfers and common-collector additions. Consuming a collector head, crediting the target eliminated head and repeated eliminated identities still require the original causal ordering. Pending obligations, stale generations, incomplete markers, scope bounds and accepted evidence remain fail closed. No payout writer, wallet, escrow, historical payment, watermark value or grant is rewritten.

Migration body/ACL drift must refuse without changes; installation can change only this helper definition, preserve private permissions and replay exactly. Missing or false concurrency evidence cannot pass. Existing accounting CI invokes this through its original runner, with input selection retained in `fixtureNativeCi.test.ts`.
