# Interrupted tournament generations retain committed stacks

A stopped MTT generation can retain several reserved, physically started hands alongside accepted hands. The existing heads-up SNG recovery authority deliberately supports one original hand and cannot truthfully dispose of this batch. Single-table Spin events have the same missing disposition boundary.

The new service-only operation records an immutable generation receipt and one child per exact reserved hand. It drains the current lease, takes the existing settlement and hand lanes, verifies the complete reserved set and all open-table roster identities, and compares each preflop snapshot against committed stacks. Big-blind antes already included in `totalInvested` are never credited twice. Private, dispatched, later, accepted or ambiguous hand evidence refuses the operation. It changes no stacks, registrations, wallets, payouts or hand history.

Only a pre-manifest park belonging to an aborted target hand is withdrawn. Accepted sibling outcomes and their park requests remain intact for genuine new-generation custody adoption. The three existing guards recognize the new receipts additively; both original HU APIs, their receipts and their constraints remain unchanged. Unknown or different-generation batches remain refused.

The existing required F06 accounting runner now exercises the connected operation, retains receipts in the existing job and qualifies the original eight-hand and successor two-hand paths alongside the new 30-hand MTT plus two Spin cases. Final native qualification passed 277 checks, including lease drain and takeover, duplicate receipts, late writers, complete rollback, post-commit failure refusal, BBA arithmetic, immutable accepted siblings, actual custody and manifest adoption, and cleanup. Direct CI routing passed 429 tests; six existing Cash input contracts and the source authorization/declaration checks passed.

The first production installation refused its three-second admission budget and rolled back completely. The corrected additive installer drains only existing atomic-hand and hand-history writers with two SHARE locks; unrelated lease readers remain admitted. A retained native scheduling counterexample proves that removing both drains would let an already executing old trigger miss a new receipt. The exact corrected installer refuses that old writer, rolls back atomically, and succeeds alongside an unrelated lease reader. Its disposition and guard bodies are unchanged.

This is locally qualified source, not a production operation. Installation and any explicit disposition remain separate, requiring fresh exact input comparisons, independently established physical process/table drain, current runtime compatibility and the normal production safeguards. It does not classify the separately observed mixed-generation event as eligible or replace the independent engine repair that prevents dealer retirement from fencing healthy peers.
