# Interrupted SNG hands retain their committed stacks

Eight heads-up SNG tables had dealt a hand, then retained a reserved F06 permit and a pre-manifest park after their original controller stopped. They cannot truthfully use the existing never-started or accepted-hand outcomes. Seven events had no earlier hands; one had 70 completed hands. Cancelling the events or crediting the forced blinds would change established money.

Migration 20260918053310 adds an explicit service-authorized `aborted_unsettled` transaction. It validates the exact original lease, permit, park custody, lifecycle, snapshot and both occupied registrations. Persisted seat stacks must equal registration chips and saved hand stacks plus uncommitted investment. Its immutable receipt permanently fences the original manager generation and hand; it withdraws only the exact pre-manifest park and retires that snapshot. It does not credit or rewrite wallets, escrow, seats, registrations, prizes or prior hand history.

The transaction first drains original manager writes by locking their protocol-2 lease, then tries the existing global/tournament and original-hand lanes without waiting in reverse order. Competing settlement wins or abort wins; an accepted or dispatched hand cannot be aborted. Lease claims, renewals, the configured request hook, and direct lease insertion reject the retired generation. The outer settlement guard and atomic/history triggers permanently reject the interrupted hand. Current preimage hashes, ACLs, original trigger bindings, request-hook configuration, snapshot trigger absence and freeze dependencies must match before installation. Freeze is checked on admission and again under the final locks.

The existing required F06 native runner now exercises this operation with actual captured F06, lease, request-hook, freeze and settlement-entry definitions. Its retained baseline proves the old generation could be reclaimed before the repair. Native cases cover competing writes and claims, committed-hand refusal, both freeze states and the v3 release boundary, a freeze beginning while abort waits, immutable receipt and terminal states, changed identities and stacks, exact replay, fresh-generation admission and old-generation release/heartbeat refusal. The eight-event fixture preserves 6,200 persisted chips = 5,870 snapshot chips + 330 forced blinds and all 70 earlier hands. Full payout qualification remains with its existing financial suites.

The CI classifier routes every F06 runner/fixture edit to the existing accounting job. Native evidence records exact input hashes, verifies deterministic migration composition and verifies all 14 replacement-function postimages with unchanged owners and execute ACLs. The shared immutable-identity trigger becomes SECURITY DEFINER under its existing postgres-only execution ACL so it can validate the private receipt; its other identity rules remain.

This is compatible with the retained 2bbc and 2ad actor propagation and fresh-process F06 contracts. Database fencing does not clear the serving process's in-memory custody. Resumption requires the normal certified engine activation already owned by the release task. No runtime injection, forced restart, scheduled repair, synthetic accepted receipt or event cancellation is introduced.

Implementation/native qualification is separate from installation, protected delivery and live recovery. The parent task owns the exact eight-object actuator, production installation/readback, certified activation and final financial/runtime verification.
