# Parked tables retain canonical movement custody

A table already excluded by its original break could not start a dealer to finish
that break: startup required hand admission, while the original park correctly
refused a new hand. The Manager now admits a movement-only owner using the latest
complete canonical hand and postcommit evidence, exact current seats and
registrations, and preserved zero-stack elimination records. Legacy sources with
no hand permits and modern sources with accepted permits require the same
canonical proof. Reserved or dispatched hand custody remains a refusal.

The additive admission transaction binds the current Manager generation,
original table lifecycle, break, custody, revision and immutable proof. The real
begin and movement transactions revalidate that evidence. A partial winning move
is proved by its original public receipt; successor custody retains the full
original roster. Changed identities, pending hands, unknown outcomes and stale
custody do not become permission to move or deal. Admission receipts reject
updates, deletion and truncation.

The runtime enters its existing pause boundary without allocating or dealing a
hand or completing a snapshot. A positively stopped, drained original can finish
its claimed move only while the Manager remains current and the admission is
revalidated inside the tracked operation. That barrier continues to prevent
replacement during an unresolved move. The movement-only pause is not released
by the ordinary dealing safety timer.

The existing accounting job directly runs the maintained PostgreSQL qualifier,
its result-validator checks and stock isolationtester races. Capture, probe,
race, opening, qualifier and result-test changes select that required job.
Artifacts are retained on success, failure or cancellation. Focused runtime
checks and the native public admission, full-manifest, two-move, custody recovery,
close and ACK path are qualified separately; the probe preserves exactly 200
fixture chips, immutable history and financial ledgers, then rolls back. Duplicate
admission commit/rollback races prove real database blocking and one effect.
Protected checks, installation, engine publication and natural live acceptance
remain separate evidence; the schema fragment declares only the pending RPC.
