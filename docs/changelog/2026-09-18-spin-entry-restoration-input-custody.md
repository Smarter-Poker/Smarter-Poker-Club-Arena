from nine input relations needed by a separate modern-terminal fixture. An RPC
response cannot establish whether its similarly named receipt table contains a
row. A whole-estate digest also cannot reconstruct omitted rows.

inventories for those relations, including an explicit empty array when empty.

frame bindings, with eight additional corruption refusals. Original financial
requests, all assertions, stage order, replay and deadlines remain unchanged.

This is input custody for a disposable fixture. It does not fabricate missing
receipts, advance a live tournament, prove positive-fee completion, reconstruct
historical hands or close the oldest alert. The previous native artifacts remain
unaltered; the new capture needs its own actual PostgreSQL execution.
