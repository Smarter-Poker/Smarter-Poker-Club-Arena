# A natural blind level reaches two spectators

The existing production MTT certificate checked real hand progression and reconnect, but did not establish that a natural blind change reached two mounted TournamentHUD instances. Its existing WebKit case now opens a second isolated context of the same reserved postdeploy account and observes the real shared tournament broadcast plus both rendered level badges. Existing hand, animation, reconnect, engine identity and no-participation assertions remain.

Before choosing the witness, a separate local session of that reserved account reads the selected table and tournament through ordinary authenticated SELECT. It rejects unknown clocks, non-running or nearly terminal events, breaks, add-on windows, accelerated timing and intervals that cannot fit another complete level plus mount time inside the existing case budget. The read session signs out locally. No owner account, service-role read, seat, registration, buy-in, forced blind transition or new fixture is used. Failure to find an eligible natural clock is unavailable evidence, never a skip or a fabricated pass.

The current source mapping is explicit: TournamentManagerBase broadcasts `level_up` with its zero-based `payload.level`, TablePage relays that event, and TournamentHUD displays `levelState.levelIndex + 1`. The browser journal retains only tournament id, level index and arrival time from the actual incoming broadcast. Both receivers must see the same later level after their shared baseline; both visible badges must render its display value. The UI assertion runs concurrently with the existing hand/reconnect proof so another later level cannot invalidate a correctly observed first transition.

Regression coverage rejects long, stale, paused, terminal and unknown clocks; checks both Realtime envelopes without retaining auth payloads; fences tournament, baseline and second receiver; and retires a pending observation if another assertion fails. Local qualification and protected publication are recorded separately from the eventual actual production witness. The existing live-engine prerequisite remains required.
