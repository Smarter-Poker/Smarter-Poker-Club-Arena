# Settlement coverage matches every hand to its committed receipt

The scheduled integrity detector compared human-only hand history with every ordinary settlement claim. Horse claims could mask missing receipts, and diamond cash uses a different lower-level receipt. The replacement counts all recent hand history against the common atomic commit using the exact hand ID, table ID and hand number. It keeps both time windows, adoption/minimum thresholds, integer rounding, incident identity, severity and hourly deduplication. No other detector section or financial operation changes.

The canonical hand commit writes history and its common receipt in the same transaction after either ordinary or diamond settlement. The migration pins that actual producer and the existing retention function, preserves function identity/authority, rejects deferred or invalid receipt uniqueness, and requires the qualified history index. Missing matching receipts are reported as evidence of missing receipts, without asserting that a particular fallback writer ran.

A fixed-width concurrent history index covers created_at plus the three identity columns. The previous exact history projection exceeded its 15-second read-only bound because the timestamp indexes fetched wide heap rows. This index copies no JSON or player array and changes no retention, grants, existing indexes, rows or table maintenance settings. Its short migration verifies the completed index; it never builds it inside a transaction. Interrupted builds require durable invalid-index/no-builder readback and one explicit same-target recovery through the maintained native session route.

Native PostgreSQL 17 qualification uses the actual non-superuser owner role. It checks complete captured source/catalog preservation, permission and drift refusals, concurrent writer progress, interrupted build/recovery, transaction rollback, and exact projection boundaries. The detector tests execute the exact old/new G blocks against synthetic ordinary, diamond, horse, mixed and NULL cases; they preserve the original threshold arithmetic and compare the bounded join with an independent unbounded identity oracle. They prove the old masking counterexample and test mismatched IDs/table/number, cutoff edges, future rows, deferred uniqueness, and concurrent snapshot visibility. The incident sink is an explicit local fixture adapter; unrelated captured financial bodies are installed for source verification and are never invoked.

All native qualifiers run through the existing required settlement accounting job. Installation, final production query measurement, protected publication and a subsequent natural audit are recorded separately; local timings are not billing savings or a full production audit claim. The earlier first-attempt index remains retained: its removal is not part of this change.
