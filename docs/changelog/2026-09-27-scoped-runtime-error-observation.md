# Scoped existing engine errors for two unresolved tournament stalls

The supported lifecycle snapshot does not expose the retained owner refusal,
and aggregate database errors cannot identify the affected tournament. Add one
explicit, manual-only read to the existing integrity workflow using the existing
repository's pinned ephemeral SSH transport. It runs only a fixed Docker log
read and returns selected tournament/table UUIDs, timestamp, context and symbolic
error families. Raw logs, player objects, credentials and SQL parameters are
neither retained nor printed. Absence remains unknown because many refusal
branches do not log their cause.

No restart, engine introspection, financial write, release dispatch, scheduled
host read or new recurring observer is introduced. The SSH key exists only in
the job's private temporary directory and is removed on completion/failure.
Health identity must remain unchanged around the observation. The native fixture
exercises actual child-process framing, bounded input/output, invalid scopes,
redaction, unrelated-record exclusion and the maintained remote entry point.

This supplies diagnostic evidence only. Source publication is not a stall fix
or a safe-recovery certificate, and the actual observation remains pending.
