# Visible achievement progress and rate history

The mounted achievement and rate-audit pages subscribed to high-write tables that are excluded from the Realtime publication. Achievement reads also swallowed any database error and permanently disabled subsequent reads, including after a different player signed in.

Achievement progress now uses scoped, cancellable authoritative reads while the page is visible and online, at a 60-second bound. Its existing published owner notification feed invalidates unlocks immediately and refreshes on subscription/rejoin. Notification owner, type and catalog ID are checked; the stored achievement must confirm the unlock before the existing five-second celebration, haptic and fanfare run. Duplicate signals do not celebrate twice. Account changes discard old responses, timers, selection and notifications. Transient read failures show an unavailable state and can recover without reloading the service singleton. Streak/progress malformed values do not become zero. The existing reward and progress write paths are unchanged.

Rate history uses the existing financial scope and RLS with two bounded, 100-row reads every 30 seconds while visible. A resolved scope from another account cannot be used, late replies cannot cross account/club boundaries, and either failed query is an unavailable history. No financial commands, SQL policies, publication membership, artwork or layout changed.

Mounted regressions exercise the actual shared observation/channel hooks and achievement reader: external progress, visibility/offline/unmount, owner/type guards, authoritative unlock and dedupe, recovery after read failure, malformed values, and delayed account/club replies. Existing deployed-route suite adds read-only authenticated cases for both pages using the reserved production fixture. Those cases perform no achievement grant, reward, rate change or money command; passing reads do not claim a natural cross-device unlock was observed. Parent delivery owns the separately qualified SELECT-policy installation.
