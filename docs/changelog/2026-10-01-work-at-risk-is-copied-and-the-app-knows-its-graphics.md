# Work at risk is copied, and the app runbook knows its graphics (2026-10-01)

Phase 7 of the mobile graphics programme.

**Other agents' work at risk.** `scripts/agent-trees-audit.sh` already names every worktree holding uncommitted edits or commits no remote has; it found 352, of which 62 sit outside the 2026-09-29 archive on SmarterArchives. Nothing made a copy of them. `scripts/agent-trees-protect.sh` does: for each such tree it writes a git bundle of the commits no remote branch has, a binary patch of the tracked edits and an archive of the untracked files under 5 MB (no node_modules or dist), with a manifest. It is read-only to every tree (no commit, stash, checkout, reset, push or delete; a bundle and a diff only read objects), pushes nothing (pushing another agent's branch would open pull requests in its name) and schedules nothing. Run on 2026-10-01 into `/Volumes/SmarterArchives/agent-evidence/2026-10-01-work-at-risk-backup`: 64 trees, 409 unpushed commits, 1,283 edited files and 546 untracked files, every bundle verified, with a README naming each tree and how to restore it. No tree was changed or removed; whose work each is to finish stays with its owner.

**The app runbook knows its graphics.** `docs/APP-STORE-RUNBOOK.md` gains "The Diamond games in the app": what a first device walkthrough should check (frame pacing, the quality governor, the wheel's lite mode, VoiceOver and TalkBack on Crash), that the scene reports carry `app_ios` and `app_android` so the first TestFlight and internal-testing builds answer "does it run well on phones" in PostHog, and that every buzz in the app goes through `@capacitor/haptics` while the iPhone browser switch renders nothing there. The native bundle (`npm run build:native`) builds with every phase of the programme. What still waits on Dan is unchanged: the Apple Developer account in App Store Connect, Xcode on the Mac and the Play Console.

Tests: `tests/config/agentTreesProtect.test.ts` (a real repository, remote and worktree: the bundle restores the unpushed commit into a clone, the patch carries the edit, the archive carries the untracked file and not an ignored one, the tree's HEAD and status are identical before and after, and a clean or skipped tree writes nothing).
