# Club Create Certification Follows The Tag-Line Accessible Name

The isolated production Club Create certificate now locates the opening
wizard's tag-line textbox by the stable `Club Tag Line` accessible-name prefix.
The field's wrapped label intentionally includes its live character count, so
an exact label-name match could wait forever even while the real textbox was
visible and focused.

This changes certification targeting only. It does not modify clubs, players,
wallets, chips, games, settings, or the opening-package transaction.
