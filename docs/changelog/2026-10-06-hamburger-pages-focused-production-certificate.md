## Added

- An operator-dispatched, one-shot workflow now runs exactly four production specs:
  Table Management, customization realtime, routed gameplay customization,
  and Leaderboard.
- Runtime evidence must contain exactly 10, 1, 1, and 2 executed cases for
  those files, respectively, with zero skipped, failed, or flaky cases. The
  existing per-file execution-honesty gate remains in addition to that exact
  count contract.
- The secret-bearing job requires `refs/heads/main` and the named
  `Production` environment. Checkout credentials are not persisted.
- The unique `certify-club-arena-menu-pages` repository event always evaluates
  the trusted default-branch workflow. There is no UI-selectable dispatch ref.
- `required_sha` must equal checked-out protected-main `HEAD`, descend from
  both correction floors, and be served exactly by both public build-info
  endpoints before fixture creation.
- The existing isolated account, staff setup, standalone setup, guarded
  always-run cleanup, annotations, first-attempt execution, and three-day JSON
  evidence retention remain intact. Before each browser file starts, the lane
  requires that file's case/global-setup allowance plus a 60-minute guarded
  cleanup reserve to remain beneath the 180-minute job ceiling. It never
  externally kills the stateful specs whose own `finally` blocks retire their
  additional accounts.
- All external actions in the secret-bearing job are immutable-SHA pinned, and
  temporary fixture credentials are removed from later action environments.
- Closing proof rereads both endpoints and requires both still equal the exact
  requested SHA. Divergence, unreadable state, or any superseding release is a
  red non-verdict.
- The workflow emits `certified=true` only after account preparation, every
  browser report, annotations, generic honesty, exact counts, guarded cleanup,
  credential scrubbing, and closing provenance all succeed.
- Artifact names contain both run id and run attempt so reruns cannot overwrite
  prior evidence. Heavy traces and screenshots remain failure-only.

## Scope Boundary

The correction lane deliberately does not rerun Cashier, Statements, Lobby,
Club Members, commerce, hamburger routes, Club Operations, supporting route
families, mobile fit, Stats, Daily Missions, financial flows, generic gameplay,
card or animation suites, live-table engine proof, SEO, or the Phase 1 seal.
The cited retained evidence remains authoritative only for the route families
and cases it actually passed; Daily Missions and financial flows remain outside
this certificate. The lane has no
workflow-dispatch, push, publication, schedule, or workflow-run trigger; only
the unique operator event can start it, and it cannot initiate or retry a
release.

The focused browser evidence is structural, functional, responsive, CSS and
asset-contract proof for the retained #SmarterCasinoRealism implementation. It
does not add a pixel-diff baseline or claim a new manual visual approval.
