# One Docker formatter terminator is not an environment variable

Docker adds one terminal newline after the names-only template, which already ends each name with a newline. The image reader rejected the resulting final empty split line even when all seven baked environment names were allowed.

The reader removes exactly that one final empty line when the input ends in two LF bytes. Interior empty lines, additional empty lines, duplicate names, unknown names and empty input still refuse. It never reads environment values. The same maintained reader serves host preflight and export admission; private-repository and immutable-image guards are unchanged.

The actual seven-name formatting regression failed before the correction. All 20 focused image-reader tests passed afterward, including the new refusal boundaries. No native image export, provider operation or production release was performed by these tests.

The next real preflight exposed modern OCI gzip blobs being treated as graph JSON: compressed blob digests differ from RootFS uncompressed diff IDs. The reader now stream-decompresses exactly one bounded gzip member, checks the compressed filename digest and decoded RootFS identity, and applies the existing resolved historical credential-header scan before any archive egress. Typed OCI graph admission uses the verified compressed-to-decoded mapping and permits the exact gzip media type. Truncation, extra members, foreign digests, credential headers, expansion and time limits still refuse.

The canonical normalizer now writes the verified uncompressed layers while preserving the original configuration bytes and image ID. Compressed and uncompressed synthetic forms produce the same canonical archive hash. Original scanner/normalizer regressions failed before; 22 reader tests and 21 normalizer tests passed after. These are synthetic source qualification, not a native export or isolated-runtime acceptance claim.

The corrected native scanner then reached an ordinary zero-byte `.npmrc` header. Only an inner resolved ordinary regular file with zero payload and `.npmrc` as its final component is admitted; every other credential component, link, directory, nonempty payload and PAX size override still refuses. Both raw and resolved header admission remain required. The actual empty-file regression failed before and passed after; no file contents were read. Native export remains unverified.

Actual Docker containerd metadata proved the native image ID is an OCI manifest digest, with one separately hashed configuration and the exact native RootFS. The reader binds the original manifest, index, Docker tag/config/layer list, configuration source labels and allowed environment names. Canonical normalization preserves the original OCI manifest/configuration/compressed layers, retaining the immutable image ID. Legacy configuration-ID archives keep their prior normalization. Original scanner metadata and normalizer configuration-ID regressions failed before; standalone 25 reader and 23 normalizer cases passed after. Synthetic archive identity proof is not a native daemon import or export claim.

The actual local post-normalization header owner now applies the same bounded gzip scanner to preserved OCI compressed layers; its connected normalizer-to-header regression failed before. Decoding is bounded in time and aggregate size, and no file values are decoded.

The next actual native refusal was index annotation metadata. One bounded categorical read established exactly three standard keys: containerd's qualified Docker image name, the release reference, and an RFC3339 creation timestamp. Only index descriptors may contain them. The name and reference must match the qualified tag and source SHA; creation is bounded parsed calendar metadata, not a new identity authority. Unknown keys, foreign names/references, invalid dates and wrong value types refuse. Original index bytes remain unchanged. Both owner regressions failed before; 26 reader and 24 normalizer cases passed afterward. Native preflight/export remains a separately required actual operation.
