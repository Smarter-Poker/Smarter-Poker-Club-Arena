# Custody refusal cases keep their own test deadline

The custody-certificate law previously launched every independent reason, five serving identities and both reason combinations inside one default five-second test. The normal pre-push suite exceeded that deadline twice (9481 ms uncapped; 5187 ms with four workers), while the same unchanged certificate passed alone.

Parameterize the outer custody reason using `it.each`. Every reason still executes all ten identity/reason combinations against the real shell certificate. Every assertion, the default five-second per-test deadline, admission control and the negative proof remain unchanged. No runtime, financial or release budget changes.
