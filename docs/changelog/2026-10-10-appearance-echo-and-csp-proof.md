# Table appearance version ordering and browser CSP verification

Authenticated partial appearance events used to carry old fields into the next row version, incorrectly refusing its complete post-image. Cache attestation now retains fields only from the same server version; optimistic selection, pending writes and genuine conflict refusal are preserved. The connected regression reproduces the classic_green/carbon_red mismatch before the fix.

The CSP sweep visits each route once after DOM content loads and observes the same lazy resources and violations. Persistent network activity no longer waits for networkidle or causes a second navigation that discards the first document collector. Unreadable collected evidence fails visibly. All routes, existing observation waits, outer deadline and strict CSP assertions remain.

Real-time law: appearance repaint is triggered by the discrete UI_THEME_CHANGED event from authenticated postgres_changes, with no polling or snapshot diff.

Validation and production proof are recorded in the owning launch checkpoint; source and passing local checks do not alone certify production.
