# Retired template recovery reads its terminal identity

A successful template retirement removes its creation receipt before Auth retirement. Replaying the same selected UUID, email and template IDs previously required that obsolete receipt even though Auth already proved retirement.

Already-soft-retired identities now validate optional ID syntax and delegate the existing guarded account terminal readback without attaching template metadata or querying the deleted creation receipt. Live actors retain database-access, exact receipt, UUID/email and custody requirements. No SQL guard or financial history changes.

The regression invokes the actual selected wrapper and existing account cleanup against a local wire: Auth read, guarded terminal RPC, Auth readback only. It fails before and passes after; malformed IDs still refuse and no fixture request or Auth deletion occurs. Production execution remains parent-owned.
