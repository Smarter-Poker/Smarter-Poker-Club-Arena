# Chip Shortage Prompt, Hero Indicators And Header Finish

Club-page arrival no longer opens Diamond Spins from a zero wallet alone. The invitation requires an observed transition into a confirmed shortage (including a wallet whose chips were already committed to an active seat) plus current server eligibility; purchase dialogs retain their existing insufficient-funds Diamond Spins actions. Account/club ownership, dismissal and replenishment resets remain scoped.

The VPIP and running profit-clock readout now anchors to the rendered hero name/stack plate. The clock prints “Your Time Clock Has Started” and the remaining server-projected time below VPIP; it never starts a local ten-minute lock or changes leave authority. Paused, unknown, expired, spectator and tournament clocks stay hidden.

The header outer rails and inward divider bars use a continuous darker finish matching the footer. All interior pixels, icons, logo, blue highlights, alpha silhouette and control geometry are preserved; the original approved artwork stays retained.

Client-only changes use existing server contracts and require no engine replacement or migration.
