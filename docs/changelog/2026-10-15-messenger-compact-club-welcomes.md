# Compact Messenger And Club Welcome Messages

Incoming messages use a white 48-pixel icon with a separate dismissal control. It appears only for active incoming messages; opening the icon uses the native dock conversation. Club relationship labels remain visible above the message history.

The hamburger menu exposes Custom Welcome Message for active sub agents, agents, super agents, co owners and owners. The server returns only the caller's eligible clubs. Each club has an independent message, enabled state and revision. Saves keep a request identity, reject stale revisions and account changes, preserve uncertain drafts and use authoritative receipts.

The World Hub owns the API and migration. Welcome messages are delivered in the joining/assignment transaction after final downline assignment, from the assigned agent or the owner when no active agent exists. Personal blocks and social restrictions are respected. No existing-member bulk send, scheduler, engine replacement or financial movement is introduced.

Local qualification: TypeScript and production build; navigation, class-name, error-handling, popup and hover contracts; real rendered editor and dock at desktop and phone widths. Protected publication and actual live proof are recorded in the operator checkpoint separately.
