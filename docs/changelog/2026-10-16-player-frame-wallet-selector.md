# Player Frame Opens Its Wallet Selector

The entire player name, avatar, ID and balance frame opens the existing native recipient-wallet selector in Cashier Send Out and Club Bank. The selected face prints the wallet label and its large balance once; the picker retains the available wallet choices and their balances. Batch recipients use the same frame. Keyboard focus and existing pending-command/recovery disable guards remain intact. No transfer, ledger, refresh or amount logic changes.

Verification covers the real mounted Cashier and Bank components, selected destination/balance updates, full-frame selector ownership, existing pending-command/ledger guards and compilation.
