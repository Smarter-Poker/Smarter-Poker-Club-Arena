# Lightning Financial Qualification Witness

The existing private-pilot witnesses do not execute the normal top-up, opt-in Auto Top Up, table cash-out or Stop Playing controls. Their absence leaves required financial and stop-flow qualification open. Add explicitly selected financial witness modes to the existing manual workflow, retaining replay batch sizing. Each invocation performs one visible normal UI action for an already admitted, previously consented, exact authorized player and pool.

Retain the actual serving client identity, current anchor and operation identity, normal response, durable receipt and relevant settlement/ledger evidence. Queued, refused, unknown, merely armed or zero-effect outcomes do not count as executed financial proof. Stop Playing is pool participation evidence and never a wallet cash-out certificate. A table cash-out must resolve the original occupancy and actual normal payout, including deferred settlement.

The witness remains finite with reserved cleanup and local sign-out. It does not accept agreements, fund accounts, create players, force hands, change game policy or bypass the normal financial doors. Source qualification is separate from actual private-pilot execution; no live financial flow is certified by this change alone.

Read-only production prechecks identified protected raw receipt tables. The witness uses the existing service-only cash-out receipt lookup and readable immutable original-funding records, matching exact wallet transaction, occupancy and pending add-on IDs. It does not change grants or install a new database function. Cash-out credit and wallet journal timestamps are matched exactly to their shared transaction timestamp.

The shared player-session opener also rejected a retained, explicitly authorized horse because its actual Auth email did not use an invented test suffix. It now validates the real Auth identity and nonempty email while preserving the horse/member/pool, ban, link, OTP and session-ID checks. The regression fails before the correction and passes afterward.
