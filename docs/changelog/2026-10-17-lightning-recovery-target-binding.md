# Lightning Recovery Uses The Current Pilot Targets

The recovery phase recorder retained legacy Classic pilot IDs and therefore refused phase capture for the normal-created Action and Madness targets. It now uses the existing read-only private-target resolver before its own-state observation bracket. Classic, foreign and malformed targets remain refused; target metadata reads do not consume the strict two-second phase bracket.

The focused regression failed on the previous source and passes after the repair. Root ran the helper and its actual recovery caller tests: 32 executed, zero failed or skipped (the caller also imports the helper tests). This manual qualification-tooling change has no engine, client or database replacement. Protected checks, merge and actual recovery observations remain separate requirements; no unobserved phase is certified.
