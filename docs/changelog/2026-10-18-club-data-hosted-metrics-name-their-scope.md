# Hosted Metrics Name Their Scope

JAQK and SHARK contribute to shared Midway games but host none of those tables.
The dashboard's physical-table hand count and pot volume therefore legitimately
read zero beside positive attributed rake. Their old labels implied they counted
every game played through the club. Cards, charts, revenue rows and the
Financials CSV now explicitly name the hosted-table scope.

The average-pot ratio mixes hosted pot volume with contributing-club raked hand
counts for union members. It is shown as Not Available there, rather than as a
false average. A missing hosted hand count likewise cannot fall back to an
attributed raked hand count under the hosted label. Standalone arithmetic and all
financial records remain unchanged.

The real stats-card component was rendered before/after at393px and1440px with
the real global styles and fonts; the new label fits and neither viewport has
horizontal overflow. Existing ledger, snapshot reuse and console tests passed86
checks. Publication and affected live display checks remain separate delivery
evidence.
