# Original accounting freshness reads both recording clocks

Completed weekly preparation and split-recompute receipts become stale when an in-period cash source is recorded or receives a later atomic-contract admission. The effective view correctly exposes the later timestamp through `GREATEST`, but filtering that joined expression made the original freshness check read a broad club-week population. An observed original pilot accounting attempt consumed its preparation budget before reaching settlement.

Migration `20261020164752` changes only the cash freshness predicates in the original `fn_prepare_accounting_week` and `fn_rakeback_recompute_split` owners. Separate existence checks read recent base sources through the existing club/recorded index and recent admissions through their original source identity. Bounded subquery barriers keep earning-period conditions from turning a generic plan back into a broad week read. The original club, earning bounds, strict cutoff, one-minute allowance, admission timestamps and tournament-fee predicate remain unchanged. No new index, financial writer, cache or alternate settlement path is introduced.

The installer pins both original function preimages, effective-view definition, reviewed column types/nullability, admission primary-key contract, ownership and ACLs. It preserves security metadata and verifies the exact native-qualified postimages atomically. Neither owner is currently in the C3 watchlist; unexpected watchlist changes refuse installation.

The unconditional native regression in `scripts/ci/test_launch_reset_floor.py` exercises the actual migration on isolated PostgreSQL17, compares original/final generic plans, checks complete freshness predicates and strict/earning/NULL/future-admission boundaries, and refuses altered source/view/column/PK/ACL contracts, wrong postimages and replay. This fixture does not simulate the full financial close. Protected delivery, actual installation and original accounting owner/settlement behavior require their own production evidence.
