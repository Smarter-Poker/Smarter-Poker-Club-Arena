# Deferred fees use their original close plan in fleet metrics

The fleet observer counted every legacy_unverified fee as unable to finish, including the exact owner-direct incident already supported by original tournament completion. Lunch Rush completed naturally with its original immutable batch and native proof; the same misleading alert then recurred for a later scheduled satellite.

The new private STABLE planner extracts the installed original qualifier validation, including historical terms, ledger/entitlement/registration identity, satellite source identity and cent allocation. The original completion writer retains its locks, completion gate, replay protection and writes, and commits the exact planned source rows. Fleet metrics exclude only fees fully validated by that same plan. Invalid proof remains counted; unexpected errors still fail the collector visibly. No financial source watchlist or generation changes.

Regression protection runs through the existing enforced owner-fee-close PostgreSQL qualification: fail-before/pass-after detector, read-only snapshots, exact planned/committed rows, invalid charge and contract, ACL, unexpected missing-relation errors, completion gate and replay refusal, plus existing concurrency and rollback cases. Final local/CI and installation evidence are recorded in the owning daily checkpoint.
