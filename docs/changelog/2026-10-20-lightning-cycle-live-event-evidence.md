# Lightning cycle witness uses the live event envelope

The finite cycle witness now accepts the maintained live EVENT envelope time
for producers such as showdown that have no payload timestamp. This fallback
requires a positive integer event sequence, rejects retained replay, and never
overrides a stale or invalid payload timestamp. The normal Time Bank selector
also recognizes the existing unlimited VIP title without buying entitlement.

Partial runs retain only the bounded hand phase observations, exact pre-action
request hand identity, time-bank context hand identity and request counts.
Cards, action amounts and raw errors are excluded. Partial evidence never
qualifies controls; completed controls require one request for each control
and the existing actual execution proofs. The timeout and single-click behavior
are unchanged.

Regression coverage uses the real producer envelope shape, stale/replayed and
unsequenced refusals, and partial browser failure with local cleanup. The live
showdown regression fails on the prior witness. Actual production qualification
requires a separately owned finite run after its runtime prerequisites pass.
