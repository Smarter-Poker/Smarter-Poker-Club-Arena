# Live SEO JSON-LD Recognition

The production SEO check reported missing JSON-LD on every public route even
though the published HTML carried valid structured data. Its script expression
required `type` to be the first and only attribute, while the published shell and
prerenderer put `id="route-jsonld"` before it.

Read script attributes independently of their order and quoting, preserving
failure for absent or malformed structured data. Cover the actual maintained
shell, alternate attribute serializations, and false type labels in the existing
SEO contract law. The existing post-publication workflow remains the verifier.
No page metadata, publisher, engine or financial behavior changes.
