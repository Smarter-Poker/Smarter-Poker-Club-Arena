# Shorter Six-Max Mobile Table

The six-seat portrait table previously used the same full-height ring as nine-seat games. Six-seat mobile tables now use a shorter, vertically centered ring while retaining the existing rail width, community-card size, player typography and controls. Nine-seat, tablet and desktop geometry stays unchanged.

The existing real-component portrait regressions cover occupied six-seat and nine-seat games, rail wagers, community cards and player clearance. The action-row checks continue to require the hero's cards and balance to remain above every preselection and decision row.
