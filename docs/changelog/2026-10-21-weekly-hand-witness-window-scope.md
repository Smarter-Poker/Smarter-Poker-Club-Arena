# Weekly hand witnesses follow their original window

The original weekly hand witness counted every immutable link resolution and escrow certificate globally. Live links outside a closed week changed those counts during its two-hour reducer, aborting the original close despite unchanged relevant sources. Read-only production samples showed global links increasing 48734 to 48741 while the audited week's link cohort stayed zero.

The witness now counts link resolutions through the original outcome's recognition time and the resolution's original union, matching the original linked reader. Escrow certificates are counted only through ordinary projected/raw hand identities in the window. Append-only trigger qualification remains mandatory. Relevant late hand, link and escrow inserts still invalidate the affected window; unrelated appends do not.

The reader, report and original advance bind the new witness and contract atomically. The exact source40 report hash changes, therefore the original inventory generation changes. Old financial proofs are neither relabeled nor rewritten. All downstream gameplay, BBJ and settlement formulas remain unchanged. No new index, job, cache writer or payout path is introduced.

Native PG17 regression covers old failure/new success, exclusive end and inclusive start, unrelated union, projected/raw identity, late relevant evidence, permissions, original preimage/ACL guards, atomic rollback, exact source40 and replay refusal. The existing required launch-reset parent invokes it unconditionally. Production installation and new-generation boundary/flow/hand verification remain separate pending evidence; no live completion is claimed here.

The existing hand-parts expiry fixture now derives its expired timestamp from the original proof-lifetime function instead of a fixed two days. With the current date, two days ago was inside the native 72-hour lifetime and after the audited cutoff, so the old test no longer exercised expiry. No runtime lifetime changed.
