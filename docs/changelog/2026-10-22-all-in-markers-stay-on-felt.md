# ALL IN Markers Stay On Felt

The ALL IN state now appears once, on the red felt puck in front of its player. Ordinary action labels retain their existing lanes; a stale all-in action cannot recreate an overhead label. The marker persists across streets with no new wager and clears for the result presentation.

Phone layouts place the puck and the chip stack independently within the same player's lane, so a combined wide box cannot force the marker above an avatar. Every marker placement fallback remains inside the painted felt. Wider layouts preserve the original side-by-side wager assembly and chip collection animations.

Real component tests cover persistent markers, stale actions and accessible status. The occupied-table browser matrix checks all-in marker count, painted-felt containment, player ownership, chip collection origins and clearance at 320, 375 and 393 pixels. Updated renders are for owner review before production.
