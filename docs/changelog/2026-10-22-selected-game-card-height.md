# Selected Game Cards Keep Their Height

The compact lobby opens a full game card only after selection. Layered MTT and
Heads-Up cards collapsed to zero height inside the details drawer's flex column
when the sections below needed scrolling. The card now retains its native aspect
height; details scroll below it for every game type.

The real-component browser regression fails on the former MTT layout and passes
after the correction for cash, MTT, Spin and Heads-Up. It checks visible card
height before and after scrolling, scrollable details and the close control.
It runs through the existing required mobile-lobby CSS Beat suite. Fixtures use
synthetic read-only data and do not join a game or purchase chips.

The owner approved the rendered layout and authorized protected delivery.
Publication and live verification remain separate required evidence.
