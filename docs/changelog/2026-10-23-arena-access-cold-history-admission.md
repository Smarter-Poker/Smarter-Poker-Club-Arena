# Truthful Arena Access Failures

The access boundary discarded database error codes, labeled every failure Offline and assured players their account was fine even when authentication failed. It also rendered an empty secondary action plate.

The client now preserves error codes and distinguishes sign-in, timeout, connection and unknown-service failures. Retry displays loading, and the secondary plate navigates back to clubs or through the existing web/native sign-in return-path helper. Existing authorization remains authoritative.

Regression protection covers all four causes, retained RPC codes, retry/loading and secondary navigation. The approved master artwork is unchanged; all four states were rendered at 393px with the real fonts.

The connected production incident exposed concurrent expensive opponent-history initialization. Its indexed and bounded database repair is delivered by the active owning memory changes, independently of this compatible client publication. This PR does not restore the temporarily revoked optional reader permission or replace the engine.
