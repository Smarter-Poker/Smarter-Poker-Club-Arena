# Jackpot Readouts Stay In The Lobby

The owner moved BBJ and Mini BBJ readouts off every live game and kept them in the lobby. The shared table display policy now always hides the persistent plates, including regular and Diamond games. The same policy prevents the table from reserving the mini row. Existing seat geometry is preserved.

Celebration eligibility is separate from banner visibility, so eligible jackpot-hit animations and sounds remain available. The lobby readout, Mini amount, details, feeds, payouts and financial rules are unchanged.

Runtime coverage checks all supported game families, both chip and Diamond banners, and hit visibility with hidden readouts. Source wiring coverage checks the shared table layer and retained lobby entry.
