# Brighter Bomb Pot Wheel Highlights

The bomb pot selector and active segments were too dim during rotation and selection. The existing pointer now carries a bright white and blue glow. The active glass segment receives a blue light wash and stronger illuminated edges; the selected result receives a red light wash with a much brighter sustained pulse. The light is drawn beneath the existing numbers, which remain fixed and upright.

The existing artwork, selected hand count, chase duration, sound gate, result hold and completion callback are preserved. Reduced motion retains the same bright selection without the pulse or rotation. This is a client presentation change using the existing engine result.
