# Lightning Cycle Witness Names What Blocked A Control Click

Run 40014858592 recorded control_not_clickable for both the Time Bank and the pre-action while Fold And Watch in the action bar clicked seven times. Playwright's own failure text names why (not visible, not enabled, not stable, outside the viewport, or another element intercepting the pointer). The witness now keeps that fixed reason and, for an intercepted pointer, only the blocking element's tag and up to four class tokens. No ids, attributes or text are kept.
