# Seat Change Matches The Gameplay Tools

The Seat Change artwork now fills the same shared tool footprint as Previous Hand, Chat and Lobby. Its button already used the correct size, but an old inset shrank the visible artwork to about 80% while the other tools had been normalized to the full Lobby frame.

The existing artwork, aspect ratio, label, action, focus and press states remain unchanged. Browser comparison uses the real controls and styles at phone and desktop widths. Queue-state buttons keep their existing readable labels and dimensions.
