# First-hand opponent contexts

Saved profiles previously covered NLH and Omaha variants only. Fixed Limit Hold'em, FLO8 and Short Deck now have distinct canonical keys in the engine, accepted-hand writer and durable reader. They never borrow another variant's evidence. The hot profile constraint replacement is reserved for the existing certified daily installer; source presence does not mean installation.

The production first-decision reader now loads existing same-variant, same-mode evidence from the other multiway size when exact evidence is thin. Exact and donor batches have independent ten-player validation bounds and travel separately through the worker protocol before the actual FAST decision and second-look frame capture. Heads-up evidence stays isolated. Reads share the original request deadline, coalesce per hand, preserve monotonic validated cache values and never initialize another donor history.

Connected worker/service regressions and the actual PostgreSQL migration chain cover first and second looks, distinct variants, duplicate observations, permissions, failure and scope isolation. Local source qualification passed; protected checks, certified installation, containing engine adoption and natural live proof remain separate requirements.
