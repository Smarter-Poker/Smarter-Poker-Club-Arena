# A premium set keeps betting

The hold'em premium rule (#8122) counted QQ+ as premium-made only as an
overpair, strictly above every board card. Live on the first engine to carry
it (2026-10-26 08:06 UTC, cash NLH), a horse with Qs Qc flopped a set on
Qh 9s 3d, check-raised the turn and then checked the river down on
Qh 9s 3d Ad 4d: the queen on board made the set fail "above every board card",
and the ace made it fail again.

A pocket pair QQ+ that makes a set (or better) with the board is now
premium-made wherever the overcards fall, so it keeps betting when checked to
or first to act, like an overpair. The law test replays the recorded river.
