# Install the owed Lightning dwell change without requesting another engine

The containing engine activated before its migration-window entry merged. The engine anchor was consumed, leaving the separately qualified mode-dwell migration absent.

The existing staging workflow now accepts an explicit database-only dispatch naming a reviewed owner window. It skips engine detection and signaling, uses the same serialized migration installer, and admits only protected main. The installer still validates the named migration and ancestor, reads installed history, waits within one bounded window for an independently owned confirmed freeze, and retains its lock, statement, transaction and commit reserves. No dispatch requests a restart or creates a break.

The date-limited manifest names only the merged mode-dwell file. Its anchor is already serving, so it cannot admit another ordinary engine release. The installed one-second migration is excluded.
