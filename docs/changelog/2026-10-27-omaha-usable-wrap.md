# Separate raw wraps from usable nut-straight draws

The Omaha draw classifier counted every immediate straight completion and treated any nine-out wrap as nut quality. A real 13-out wrap on a monotone board therefore received the same nut-draw aggression and pressure allowance as clean nut draws, despite a legal opposing flush beating its straight. Paired-board and dominated low wraps had the same classification problem.

Keep raw straightOuts and bigWrap intact. Add nutStraightOuts using the existing exact-two-hole made-straight authority, counting only nut-straight completions on unpaired boards without a possible flush. The existing nine-out requirement now applies to usable nut-straight outs before awarding nutty quality. Existing nut-flush and nut-low classification remains intact. This bounded physical enumeration adds no Monte Carlo draws, range widening, new betting threshold, forced fold, or private opponent information.

Real evaluator witnesses cover PLO4/PLO5/PLO6 monotone, paired and dominated wraps, with clean high-wrap and nut-flush positives. Connected decision tests show the actual EV consumer receives 0.36 for the dirty wrap versus 0.48 for the clean one under the same controlled MC input: the existing 0.12 pressure allowance no longer goes to the dirty wrap. Existing raw-draw implied credit stays separately priced. The observed aces hand is physically one pair with four nut-gutshot outs, not a wrap; its historical range/equity/decision owner remain unknown. These checks do not establish every weak-pair call wrong or prove live profitability. Original actual-estimator cheap-call and strong-made controls remain in the focused suite.
