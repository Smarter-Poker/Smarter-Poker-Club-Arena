# Roster readiness and browser diagnostic retention

A retired Supabase callback could arrive in the same React batch as an authorized engine READY and mark the member roster degraded. Fence fallback status and payload callbacks synchronously at READY, while preserving paid fallback after actual engine loss and identity changes. Regressions cover CHANNEL_ERROR, TIMED_OUT and CLOSED during handoff.

Install the already specified seven-day browser bus_event_log retention through a bounded daily owner: at most 50,000 expired rows, short lock and statement budgets, and application execution denied. Installation itself deletes no rows. The existing required native PostgreSQL data-console qualification exercises expiry boundaries, limits, permissions and replay refusal. No financial, hand-history or managed Realtime data is deleted.

Paid private-record Realtime remains enabled for cached and native compatibility. This change does not install or activate the independent gateway, change native distribution or retire paid traffic. Small diagnostic retention does not shrink provisioned disk or establish a lower total bill.
