# Runtime privileges preserve schema boundaries

The weekly payout reached its original reserve helper, whose private TEMP-table REVOKE was rejected as production schema DDL. PostgreSQL reports no object address for GRANT/REVOKE. The guard now recognizes only these authoritative event tags as permission churn, matching CLAUDE rule5. Its public CREATE/ALTER/DROP, freeze, advisory and audited emergency rules are unchanged. The private reserve TEMP ACL remains unchanged.
Sixteen focused native PostgreSQL cases reproduced the failure and validated the exact transition using the original reserve helper. Production installation and payout verification remain separate root-owned operations.
