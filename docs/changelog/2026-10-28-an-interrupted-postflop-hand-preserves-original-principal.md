# An interrupted postflop hand preserves original principal

A dead tournament generation can leave an incomplete river snapshot and an unresolved permit, with no accepted result or retained settlement request. Exact controller continuation is unavailable. The existing preflop-only disposition correctly refuses that river, holding the whole generation and its other tables.

The same event-owned transaction now has a separate `misdeal_voided` shape for an interrupted NLH/PLO4/PLO5/PLO6 postflop hand. It requires unchanged original seat and registration principals, exact last accepted atomic/history boundary with completed postcommit, original seat identity/join time, complete snapshot contribution conservation and no competing committed/private/retained/dispatch/discard/park state. Later chairs must join after the snapshot and hold no old-hand cards. Unknown proof refuses the entire transaction.

This is a void, not a resumed hand or an invented winner. It writes immutable generation/per-hand receipts, closes the reserved permits as `aborted_unsettled`, completes the preserved snapshots and permanently fences late writes through existing guards. No chips, registrations, seats, wallets, accepted commits or hand history are written. The existing generation transaction may restore the blind clock from evidence, as before; it preserves the current lease. Old preflop and other misdeal branches remain byte-identical. There is no repair loop, restart, new publisher or human-specific exception.

The maintained native PostgreSQL runner reproduces the old refusal before installation and verifies the mixed two-preflop/one-river generation with 15 originals and three later chairs, whole-generation rollback for a bad sibling, exact unchanged principal/history/current lease, authorization/freeze refusals, concurrent duplicate receipt replay and existing late-commit/history fences. Source-law coverage pins exact pre/post images and the unchanged old body. This source qualification does not establish production installation, a live recovered event, controller resumption or Horse Brain profitability.
