# Own playing earnings retain historical AGENT destinations

The earning constructor now includes the earning agent's observed historical
agreement. Ordinary playing-agent earnings enter the original commission stage,
while direct-owner 70% earnings preserve their full amount. A historical
promotion within one period can create PLAYER and AGENT destination legs from
the same original payer without changing that payer's aggregate cent amount.

Versioned immutable sidecars preserve original source, certificate and transfer
row shapes. The existing unpaid R0 request owns bounded interpretation and
cache invalidation. It limits source IDs before historical evaluation and retains
immutable unchanged review results so each request advances. Paid
source/capture/R0/R2/R3 replays retain original receipts,
including after a separate approved correction. Suspended agents retain earned
AGENT payments without reactivation; unavailable destinations refuse.

The original weekly pause guards remain composed in all three financial stage
owners. Installation requires that exact phase migration and the unchanged
original 65/GEN authority. New AGENT deferred documentary trigger DDL requires
the existing daily maintenance installer. Source qualification runs the whole
migration and actual document owners in the existing accounting CI path.
Noncashout invoices are history-only, with no Messenger message.

This change is source-only. Protected merge, production installation, historical
correction payments and affected live verification are separate states. See
`scripts/qualification/own-agent-v1/README.md` for exact qualification scope and
controlled native boundaries.
