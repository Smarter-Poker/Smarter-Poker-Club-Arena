# Suspended agents retain earned credits

An agent wallet can be suspended after its rakeback was earned. The approved adjustment executor now accepts an existing active or suspended agent wallet, while preserving the frozen-wallet refusal, exact approved intent, original bank funding, journal invariants and durable replay receipt. It changes no account status or access.

The existing native qualification executes both migrations, checks their exact transition and unchanged ACL/metadata, and verifies a suspended-wallet correction rolls back with the wallet status unchanged. Production installation and actual payment verification remain separate.
