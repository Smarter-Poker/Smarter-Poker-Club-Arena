# An unavailable field keeps its blind level

The ten-minute admission hold exception now requires another current table without an admission refusal. Previously every failing table independently aged out, permitting a blind publication against an entirely unavailable remaining field when a recently closed table had supplied the level's hand-completion witness. Healthy remaining tables retain the existing finite minority-table exception.

The regression drives the actual manager transition, fails on the previous implementation, holds after the correction, and resumes the existing publication path when a dealer is admitted. Existing break, restart and atomic publication tests remain applicable. This source fix does not dispose of interrupted hands, change stacks, infer payouts, or reconstruct the incident's historical clock; those require their separate durable evidence.
