# Club Data searches the requested player identity

Live verification found KingFish absent from Data search because the generic roster matches upline names and returns the first twenty alphabetical rows. Club Data now uses a bounded identity-only reader: authorized record access and alias, username or player-number matching precede the limit; exact identities rank before prefixes and other substrings. The generic Players roster remains unchanged.

The reader reuses the maintained Data scope and roster authority, refuses ordinary players and unauthenticated calls, and returns only permitted record identities. Existing account, club, query and abort guards remain active. Native PostgreSQL qualification reproduces the old upline crowding with thirty downlines and verifies the actual reader, exact ranking, privacy before limiting, role/club boundaries, ACL, rollback and replay. Client and service regressions verify direct record routing and malformed/denied/stale responses. No financial data is changed; no engine replacement is needed.
