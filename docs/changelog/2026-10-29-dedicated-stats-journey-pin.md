# Supply the qualified pin to the dedicated Stats proof

The dedicated published-pagination lane pinned LIVE_SHA, while its one browser case had been upgraded to require DOWNLINE_JOURNEY_SHA. The missing producer meant the supported lane would skip rather than exercise the current case.

After the existing fresh two-origin pin, the lane now runs the same maintained source qualifier as the normal Stats suite. It exports the qualified journey pin only when it exactly matches that original dedicated pin, and retains the qualifier receipt in the same proof artifact. Unknown, refused, malformed or changed pins cannot reach the browser as success. The fixed empty-payload selector, isolated account, single Chromium case, zero retries, before/after origin checks, actual asset assertions, first-attempt validator and verified cleanup stay unchanged.

A connected regression failed against the unwired protected workflow, then executes the actual corrected shell step to prove the qualified handoff and refusal cases. The normal Stats handoff remains covered in the same maintained test file.
