# Find Your Game Starts With Cash Games And Tournaments

The club lobby now starts with a centered Find Your Game heading and two large
buttons underneath it: Cash Games and Tournaments. Both start closed on ordinary
entry. Selecting one opens only that family's controls and game list; selecting
the open button closes it. Live Club Schedule and the heading's game total are
removed.

Cash Games contains All, NLH, PLO and Limit. Tournaments contains MTT, Spins and
Heads Up. Advanced Filters stays within the selected family. Saved tab, sort and
filter preferences retain their existing storage path; opening their matching
family restores the saved tab. Explicit embedded tournament landings and shared
game links still open the requested family. Creation access and game admission
paths are unchanged.

The two buttons use the lobby's existing blank painted plate at its native ratio,
with fitted live labels and accessible expanded state. Mounted-page regression
coverage checks closed entry, separate controls and rows, switching, closing and
the filter sheet. The existing mobile chrome browser suite checks phone and
desktop geometry and button behavior. Existing live browser tests now open the
applicable family before selecting a game tab.

Client-only delivery; no engine replacement, migration or financial change.
Publication and live verification are recorded in the task checkpoint.
