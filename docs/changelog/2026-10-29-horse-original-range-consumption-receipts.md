# Original public range-consumption receipts

The private decision journal retained original inputs and accepted actions, but not the transient range bands and postflop reads that actually reached the reference equity sampler. Recomputing them afterward cannot establish original consumption.

A decision-local collector now captures the already computed, post-option range inputs at the existing single/multiple-board postflop Monte Carlo calls for NLH/PLO4/PLO5/PLO6/PLO8. Sampler-owned bitmasks distinguish inputs supplied, opponents actually reached, band/conditioning branches entered, the actual Omaha tier and actual `bigBet` short-circuit accesses. Adaptive exits record completed samples; invalid decks record none. No additional deals, RNG calls, per-sample arrays/callbacks/logs, public fields or global collector are added. PLO8 means four-card Omaha Hi-Lo eight-or-better.

The closed private receipt is capped at 4 KiB and three boards by nine indexed opponents. It binds the complete original FAST or DEEP request digest, read-frame digest, actor, street, variant and original opponent order. It contains no sampled opponent cards or duplicated opponent identities. Collection starts only when existing journal capture is configured and has a sink; writer capacity and durable acceptance remain the journal owner's responsibility. Old or missing receipts remain unavailable. The existing original-hand/execution reconciliation is still required to associate computation with an accepted action; later policy replacement, strategic improvement and profitability are separate claims.

The new module and its canonical journal encoding dependency enter the existing reference-source digest registry. No source exclusion, qualification restamp, game rule, strategy option or admission authority is introduced.

Verification: the real worker regression fails on the original worker because the producer receipt is absent. The candidate passes 74 tests across nine focused suites, including 21 new receipt/worker tests, plus server TypeScript. Five-variant real chooser comparisons preserve action, effects and RNG with capture on/off. Tests cover call/raise distinctions, V16/V40 stripping, per-board demotion, physical early termination, adaptive sample counts, invalid decks, maximum receipt size, context forgery, FAST/DEEP binding and private-journal-only delivery. These are source/regression results; protected merge, installation and actual affected natural-case verification remain outstanding.
