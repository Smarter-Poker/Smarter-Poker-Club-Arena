# Player Record stays put while it is being used

The member detail page no longer reloads the entire record and downline on window focus, tab return, network return, record-channel reconnection, or UTC midnight. Source events validate authority without replacing identity, performance, presence, downline, note drafts, or the selected date range. Role options still follow the viewer's current authority. Explicit retries, date selections, and completed administrative actions retain their existing reload paths.

Precise wallet updates and authoritative permission withdrawal remain live. Wallet patches no longer advance the shared section revision, so they do not refetch the Watch At Table, Upline, and Win/Loss cards. The Win/Loss card's own Chicago calendar boundary and the pending cashout panel's focused financial reads remain unchanged.

Regression coverage mounts the real page, preserves a dirty note through focus/online/visibility events, verifies fixed ledger dates across midnight, retains source-event security checks, and preserves wallet/access-denial and explicit retry behavior.
