# Complete MTT launch fields

The launch path read active registrations, adopted tables and live seats in single PostgREST requests. Fields beyond the response cap could be omitted from construction and refused by the final funded-field proof. The independent 1,001-player regression returned false before this change.

Expected-entry capture, table construction and final launch proof now use the existing keyset reader, including the seat row identity. Every read must be complete before it can authorize construction or certify launch, and every page retains the manager lifecycle fence. Adopted tables retain their creation order after paging. Exact funded stacks, coordinates, counts and database seat-assignment receipts remain required.

Real manager tests cover the exact page boundary, 1,001 players, 9,001 players spanning more than 1,000 tables, a mismatched final-page stack, and later-page roster/seat failures. Source contracts pin the replacement completeness checks. This is a large-field failure mode, not the established cause of the currently stalled smaller tournaments. Runtime publication and live proof are tracked separately from local tests.
