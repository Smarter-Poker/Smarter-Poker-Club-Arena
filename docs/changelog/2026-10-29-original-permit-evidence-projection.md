# Publish the original permit's evidence identity

A successor manager positively claimed a retained original hand, then refused its admission with `f06_recovered_original_projection_unproven`. The canonical `fn_f06_hand_number_state` response omitted `unresolved_permit.evidence_id`, while the serving manager requires that actual reserved permit's evidence identity to be null. JavaScript read the omitted key as undefined, so a valid claim could never pass that comparison.

The forward migration adds the actual `h.evidence_id` from the same selected permit row to the existing JSON projection. It preserves the installed shared table lane, original identity fields, admission decisions, owner, security mode, permissions and configuration. It does not invent a null value, change chips, dispose of hands, or require an engine replacement. Existing manager admission can consume the corrected response and resume the retained original.

The manager fixture now additionally refuses an explicit non-null evidence identity. Reproducing the actual old response shape made both durable and legacy positive admission cases fail; the corrected producer shape passes all 68 manager cases. Server TypeScript compilation passed. Isolated PostgreSQL 17 qualification passed 24 steps against the exact installed shared-lane predecessor: the old missing-key case fails, actual null and non-null evidence identities survive projection, wrong lease authority and drifted function/ACL preimages refuse, reverse substitution preserves every other function byte, and row data plus transactional catalog rollback remain unchanged. The actual catalog live-proof expression is false before and true after installation. The owned cluster was removed. Installation and live readback are separate; source preparation alone is not production recovery.

An originating continuation failure can occur before successor admission. That separate failure remains under investigation; this projection correction does not claim to identify or eliminate every originating failure.
