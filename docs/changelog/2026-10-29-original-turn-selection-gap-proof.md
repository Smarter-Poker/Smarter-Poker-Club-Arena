# Original turn selection and tournament metadata diagnostics

The existing private inspector adds a separate version7 original-turn probe. It binds record hashes/source, unique accepted hand and original full-list ordinal, actor/seat, producer/turn/sequence, the actual whole-hand reconciler and canonical input/read-frame validators before returning any stored action or amount scalar. Failed or ambiguous evidence stays unknown. Earlier versions and their matched-risk/all-in observations retain their existing contracts.

The probe preserves stored JSON amount absence, null and numeric zero separately and names the exact failed current turn-census selection conjuncts. Closed original withdrawal receipt owners/verdicts and exact reference-versus-selected comparisons are reported without certificates, proposals or a unique-cause claim. A genuine authority withdrawal can therefore remain visible even when the capture and final selected action differ. It does not require the disputed selection predicate to pass before diagnosing it. Variant and mode are explicitly metadata from the captured original snapshot, not an independent database cohort classification.

For a bound original NLH tournament river, the existing installed pure tournament classifier can return a closed eligible/excluded/gap reason. This is derived classification of that original snapshot, not a recovered stored reason, policy replay, causal attribution or qualification. Missing/unrecognized optional classifiers remain unknown independently of other bound selection facts.

Input/output remain bounded to8192bytes/six original targets. The helper stays below its existing65536byte injection cap, retains its finite five-second scan and existing transport settings. The existing128MiB Node old-space option is not a whole-process memory guarantee. No cards, boards, graphs, raw errors or operator paths are exported. No policy, threshold, kernel, database, capture, provider or strategy default changes.

Regression coverage uses actual journal/witness/binder/reconciler/read-frame/classifier components, checks agreement with the maintained census including an authorized withdrawal, exercises the existing Python encoder/transport/sanitizer, and preserves legacy probes. This control identifies missing fields/equality failures; an actual diagnosed defect still needs its maintained source fix and affected-live proof.
