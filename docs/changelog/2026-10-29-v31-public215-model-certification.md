# V31 exact public-state value models

The existing V31 loader admitted only sparse hand matrices. Those matrices cannot
represent the frozen 215-feature value model, and the six-hour refresh did not
provide an explicit acknowledgment from each decision worker after promotion.

This change adds numeric-only HistGradientBoosting programs with exact binary64
values, bounded tree shapes and one globally selected model variant. The original
matrix representation remains available. Parametric advice uses only the actor's
cards, chronological public board and approved ROOT template; it executes inside
the existing decision worker. The receiving Linux image builds the maintained
N-API kernel from source. No workstation binary, executable model serialization,
opponent private cards or model-selected range is admitted.

The independent SQL authority binds genuine approved M1 captures, public feature
and partition protocols, training provenance, exact program bytes and Linux
all-head parity/cost receipts. Private model preparation and immutable freezing
precede opening the committed independent M2 selection. Preparation is not a
runtime cell or qualification. SQL recomputes public physics and predictions;
missing audits fail closed. Existing source, quality, sealing, league evaluation
and promotion requirements remain in force. No threshold or execution budget is
relaxed, and old rejected releases remain rejected.

A request-scoped loopback control loads only the authoritative active dataset and
requires eight distinct worker acknowledgments with exact dataset checksum and
cell count. Status reads resolve an unknown outcome without replaying promotion
or restarting a healthy engine. Store admission yields between complete model
cells and atomically swaps the entire validated snapshot; stale overlapping loads
cannot overwrite a newer explicit request. Decision FIFO and deadlines remain
unchanged.

Focused verification covers numeric/tree parsing, independent PostgreSQL feature
parity and genuine source lifecycle fixtures, loader pagination and stale loads,
worker terminal acknowledgment, loopback authorization, concurrent duplicate
requests and partial/mismatched acknowledgments. Required directly triggered CI
runs the retained checks. Synthetic fixtures do not establish production model
quality or actual loading. Certification, protected delivery, installation,
promotion and affected live proof remain separate acceptance requirements.
