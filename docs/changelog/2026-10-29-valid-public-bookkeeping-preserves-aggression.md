# Public bookkeeping preserves aggression evidence

Recorded Burls hands with a public run-it-twice board or forced bomb-pot ante were rejected by the action validators, making otherwise complete aggression evidence unavailable. The SQL helper and committed public stats builder now recognize the exact producer envelopes: river board 2 or 3 with five distinct valid public cards, and positive forced dead preflop bomb antes. These records add no bets, raises or calls. Unknown and malformed actions still invalidate measurement. Public board metadata never enters the stats frame.

The migration replaces the existing helper in place, preserving its OID, service-only permissions and original fact-insert trigger. It rewrites no historical facts and introduces no background work. Two anonymized public-action histories from the affected Burls hands qualify both the builder and native PostgreSQL helper. Focused regressions failed before the correction and pass afterward; invalid board indices, card formats, duplicate cards and malformed forced antes remain unmeasured. The PostgreSQL fixture uses a shorter task-owned scratch name to fit Unix socket path limits on the shared-capacity volume.
