# Credit lines track agent advances only

Owner direction: credit lines are tracking only. Spendable chips are the funded Agent Wallet. Weekly top-up invoices are max(0, credit line minus Agent Wallet), captured before commission and rakeback and preserved on retries. Credit Available is removed from the affected member, cashier and agent displays.

The send owner refuses unfunded transfers. A new service-only weekly basis is captured by both live R2 implementations before earnings. Invoice payments restore the Agent Wallet from the same-club Player Wallet or a club bank funded external payment; operation/reference replay cannot repeat the transfer. Successive statements supersede unpaid tracking statements rather than collect the same shortfall twice. Existing legacy invoices and receipts remain historical.

No engine runtime change or new scheduled job. Install the protected migration through Apply Merged Migration, then use the existing Club Arena client publisher. Native qualification exercises the final installer, actual R2/R3, funded top-up, receipts, rollback, exact replay and chip conservation on synthetic balances. Live verification must separately read installed hashes and the two served build identities and affected UI. A native synthetic weekly close does not establish a naturally scheduled production close.
