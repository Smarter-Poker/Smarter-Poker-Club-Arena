# Retire a clientless current MAIN Inspector before recovery announcement

The old engine's preexisting MAIN Inspector prevented the release transaction
from requesting a recovery window. Readiness rejected every listener, while the
checkpoint correctly refused to adopt one it had not opened. Repeating the
existing observer could not resolve that state.

The immutable release control now has one finite EED-only preannouncement
retirement. It proves the actual inherited engine lock, current request/control
and systemd invocation, sealed image, live healthy instance, container/start/PID,
loopback listener and exclusive MAIN ownership. A fsynced O_EXCL claim binds the
fresh endpoint and kernel tuple before granting attachment. Immediately before
fixed native Inspector shutdown, the kernel must identify exactly the helper's
own reverse client/server socket pair. No profiler, GC, signal, game evaluation,
forced action, restart or payout is used. Native shutdown must acknowledge and
close remotely; a competing local close frame is forbidden. Positive listener
absence and unchanged healthy process complete the receipt. Unknown outcomes
retain the claim and cannot retry.

The preannouncement operation has one absolute twenty-second deadline capped by
the existing request expiry, reserving five seconds before native shutdown.
Original checkpoint guards, all-physical-engine custody, forty/five-second entry,
285/245/135-second reserves, maintenance windows, freeze/seal and v3 thaw remain
unchanged. Immutable controls are installed only through the existing provider;
this source does not hotpatch an active generation or withdraw another owner.

Regression protection uses the existing required Server Engine suite: real native
Inspector transport, actual Linux proc/socket ownership and combined retirement,
plus isolated durable claim/identity/expiry/unknown-outcome tests. Mac Linux-only
skips are explicit; hosted Linux must execute them without skips. Deployment and
all15 original hands/all128 funded seats still require actual live evidence in
the existing recovery checkpoint.
