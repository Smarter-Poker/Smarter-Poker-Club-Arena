# Admit one genuine M2 board to the existing independent SQL audit

The existing numeric build proves 57 M1 and eight independently selected M2
nodes per context, but its Linux receipt prepares only the approved parity-case
boards. Heldout scoring refuses an M2 board whose full SQL audit is absent.
There is no authenticated caller for deriving those missing audits from actual
M2 admission records. A caller-supplied board or selection receipt is insufficient.

The new service-only wrapper derives one board by a bounded ordinal from the
immutable M2 journal. It checks the unchanged complete selection, current source
headers, pre-opening frozen model authority and runtime cell bindings before
calling the existing physics/audit implementation. It reads no seed or labels,
changes no scientific algorithms or gates, and returns only bound metadata.

Native qualification exercises the actual new SECURITY DEFINER function in an
isolated PostgreSQL 17 database with controlled existing-helper fixtures. It
covers authorization, bounds, exact model/receipt/source/selection admission,
chronological board ordering, delegation and metadata response. It does not
repeat or claim qualification of the unchanged physics algorithm or actual M2
data. The existing required V31 native entry invokes this focused qualification.
No migration is installed by this source change. Root holds merge/installation
until the active R2 operation is terminal, preserving its schema/transport state.
