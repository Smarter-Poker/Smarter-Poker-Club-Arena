# Retained prepared hands keep their custody number

A tournament successor drain can stop a positively retained sequence-zero controller before its first action. The real dealer finally previously rewound its hand number because no hand had started. Native stop joined that finally and then labelled the original players' time-bank custody with the preceding hand number.

The dealer now preserves the number only for the same positively retained controller and exact prepared permit, with confirmed retention, matching table/hand identity and attempted permit state. Ordinary unretained attempts still rewind and use their existing cancellation owner. No hand is started, settled, discarded or replaced by this correction.

The regression runs the actual dealHand, permit reservation, original retention, physical pause and manager stop. It checks the unchanged private capsule/controller/permit and the exact hand number and bank values passed to native stopped custody. The pre-fix candidate failed with 1000041 instead of retained hand 1000042. Existing unstarted-permit and prepared-successor tests remain required; the ordinary unretained case explicitly checks rewind.

The separate proposed frozen-reader migration and legacy guard expansion are archived follow-up work and are not included. This change does not certify deployment or live recovery.
