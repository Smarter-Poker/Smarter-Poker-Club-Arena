# Reusable satellite value awards

Future unavailable satellite seat prizes retain their full funded value as entry-only tickets for another eligible event with the same full price and asset. Bubble cash and historical receipts keep their established behavior. Chips use ticket escrow; Diamonds use native prize-bank, ticket and entry custody with zero wallet movement. Existing membership, capacity, freeze, feature and price guards still apply.

The directly affected refund entitlement validator now checks the chosen event split against its immutable funded admission instead of requiring a new value ticket to retain its original target split. Legacy ticket, wallet and satellite-seat paths are preserved.

Isolated PG17 qualification passed both funded assets, fee/bounty splits, conservation, source replay, duplicate entry, rollback, no cash conversion and private issuance permissions, including deferred constraints. App compilation and1246 focused source tests passed. Integration, protected delivery, installation and live readback are separate pending acceptance items in the existing checkpoint.
