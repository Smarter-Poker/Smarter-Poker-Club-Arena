# Tournament Rows Use A Clear Event Schema

Tournament schedules now use black backgrounds, a full red outline for pinned events, centered favorite stars and one silver guarantee marker per compact row. The redundant Top Event badge is removed. Satellites use yellow left rails, all bounty formats green, freerolls blue and freezeouts white; rebuy, speed and stack formats use the same maintained schema in compact and wide rows. A guarantee no longer overrides the event-type marker.

Open late registration is labeled Late Reg. The previous presentation replaced that derived status with Running even while its actual-start countdown remained open. The corrected label follows the same status used by sorting and filters and changes to Running when registration closes.

The October 31 owner request supersedes earlier tournament badge and tinted guarantee styling. Cash row styling, static Game headings, direct numeric sorting, pinned order, saved filters, truthful clocks and financial records retain their existing behavior. Regression coverage checks both row layouts, overlapping guarantee/type facts and the live status boundary.
