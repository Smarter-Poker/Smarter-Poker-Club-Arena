# 2026-09-27: a never-started permit does not hold the stopped bank

Six tournaments lost their engine lease at 2026-09-26 15:07Z while each of their table engines held one F06 hand permit reserved for the next hand and never started. The stopped-custody park refused `hand_after_custody` over that `reserved` row, every manager stop failed "retained time-bank custody" (about 16,400 retries per manager over 24 hours), `stopped_bank_custody_stuck` held the restart certificate shut at 26 consecutive hourly countdowns, and no engine release was admitted between 2026-09-26 14:05Z and the fix. The ordinary cancellation door, `fn_f06_cancel_prepared_hand`, requires the live lease the engine had just lost, and the park could not tell a reserved-never-started hand from a reserved-and-dealt one because `permit.start` is a fence the engine holds locally.

The engine now attests, by id and hand number, the one permit above its custody that it never started (phase `reserved`, `unknown` or `terminated`; a permit whose `start` ran is never attested). `fn_park_stopped_time_bank_custody` takes that attestation as two optional arguments and, in the park's own transaction, closes the permit `never_started` with the same receipt the ordinary door writes, only when the permit is still `reserved` with no evidence, its generation no longer holds the lease within `fn_engine_lease_stale_seconds()`, and no durable witness of a start exists (the exact witness set `fn_f06_cancel_prepared_hand` refuses over). Every existing refusal, the lock wait, the ACL and the security posture are unchanged; the eight-argument callers (the fenced-manager trigger and every earlier engine release) resolve to the same function through the defaults. The engine treats its preparation as resolved only when the database names that permit back.

Migration `20260927150704_a_never_started_permit_does_not_hold_the_stopped_bank.sql`; law test `server/src/tournament/aNeverStartedPermitDoesNotHoldTheBank.law.test.ts` (9 tests). The release admits only the bank the database wrote; a refusal still writes nothing and keeps the certificate shut, and a hand that may have started is never voided by this path.
