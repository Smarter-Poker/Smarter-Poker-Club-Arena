# Table Management sections are their own pages

Club and union Table Management printed every tool inside one painted console
whose title changed: the Game Board, Ticker Management, Club Messages and the
table creators read as interchangeable screens in the same window. Each surface
is its own composition now, drawn on its own approved frame family, and the
section strip is page navigation outside every frame.

The Game Board keeps the spade console with the spade crest and a flat foot.
Ticker Management draws the shark frame with its one plate, Save Ticker. Club
Messages draws the riveted frame with its two plates, Save Identity and Publish
Banner, and a heading that names the copy the first plate saves. The Add Table
picker prints its own header on the black over an engraved rule and draws no
frame around the painted game cards. Table setup draws the spade frame with the
flat head in both the embedded and routed modes, and its form no longer prints a
title the console head already carries. The tournament creator moved to the
riveted frame at the riveted width. Edit Game is riveted, Schedule Close is the
spade frame with the flat crest, Contract History is the shark frame, the access
check wears the flat crest and a refusal wears the shark frame with one Return
plate.

Sections are addressed rather than remembered: `?section=ticker` and
`?section=messages` on the existing club and union routes, replaced rather than
pushed, so Back still leaves Table Management and no history step strands a
draft. One route keeps the page mounted across all three, so the management
feed, the access state and the draft guard are shared while the pictures are
not. The hamburger menu navigates with buttons rather than links, so it asks the
page before it leaves through a navigation guard the page holds while a draft is
unsaved.

The states say what is true. A board that has not read yet, or could not, no
longer claims to hold zero games, the health rail stops reading for ever when
the board read that carried it failed, and a refused read prints a plain Title
Case sentence instead of raw browser error text. Over a dimmed board the spade
glass no longer lets the board's lit text read through a dialog's copy, primary
plates are lettered in white, disabled fields are lettered quietly, and the
divider between the strip's columns stops printing after the last one.

No service, command gateway, contract, realtime or access behaviour changes.
