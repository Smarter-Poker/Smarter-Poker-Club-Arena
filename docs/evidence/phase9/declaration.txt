3. Comparison (independent re-settlement)
-----------------------------------------
Reference: server/src/benchmark/OmahaReference.ts (offline, not the
production settlement path), driven by the reused comparison script
p92-natural-compare.mts generalized to the whole population.
Inputs, all as recorded: boards (community_cards/2/3 or community_cards +
rit_boards), recorded hole cards, contributions replayed from actions (call,
bet, blinds, straddle and antes are chips added; raise and all_in are
resolved against the next captured publicNode invested totals, else
unambiguous with no street bet, else a single unresolved one by recorded
pot_size; a shared big blind ante is pooled dead money), the button seat, and
chip unit from the captured public node (0.01 if absent on chips).
Checks per hand:
  (a) pots: reference pots (amount to the cent and eligible seat set, in
      order) equal recorded pots exactly;
  (b) conservation: recorded winners sum equals pot_size - rake_amount -
      bbj_amount exactly, to the cent;
  (c) per player: recorded payout within strictly less than one cent of the
      exact pro-rata share  reference pre-deduction award x net / gross;
  (d) per board and half: recorded winners_by_board entry within strictly
      less than one cent of reference board share x net / gross; an absent
      entry for a positive reference share is a mismatch; for an
      uncontested hand (one non-folded contributor) halves are summed per
      board, because no hand is scored;
  (e) deductions, reported separately from (a)-(d): expected rake =
      min(round(pot x pct), cap tier by players dealt), pct capped at 5 when
      two are dealt; expected BBJ = feeBB x big blind when enabled and dealt
      >= minPlayersDealt; from the deductions configuration captured on the
      hand's own public node. No captured configuration -> deduction unknown.
Verdicts:
  MATCH            (a)-(d) all hold and every input was recorded.
  MATCH_PARTIAL    (a)-(c) hold; (d) unknown because winners_by_board is not
                   recorded. Never counted as a full match.
  MISMATCH         any of (a)-(d) fails. Exact numbers reported per hand
                   (hashed hand id only).
  EXCLUDED/UNKNOWN by reason, never zero-filled:
    live_eligible_cards_not_recorded (a mucked/unrevealed live contributor),
    replay_disagrees_with_capture, replay_pot_size_disagrees,
    unresolved_raise_amount, unhandled_action, pots_not_recorded,
    winners_not_recorded, board_incomplete, board_count_disagrees,
    variant_not_in_reference, reference_threw.
A mismatch is a finding; money is never changed.
