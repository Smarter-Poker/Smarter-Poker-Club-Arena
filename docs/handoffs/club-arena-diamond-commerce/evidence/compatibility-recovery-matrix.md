## 3. Engine and client do not depend on each other

The client never calls the engine for commerce, and the engine never calls a client. The only coupling is through database rows. A new client with an old engine therefore changes only **when** renewals, refunds and notices happen, never **whether** a charge is correct. Every due action re-validates authority, price, lateness and funds at execution (M3:903-963). **Billing is never in the next-poker-action path.**

- RM `D21 / D28 no commerce trigger sits in the gameplay or seating path`.
- M4:464-472 asserts this at install.
