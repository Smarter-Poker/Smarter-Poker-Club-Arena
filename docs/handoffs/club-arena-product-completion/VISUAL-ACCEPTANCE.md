Assignment CA-PRODUCT-COMPLETION-2026-09-22, Phase 5.6. Base `ee8a0de44`.
Date 2026-09-24.

## How it was rendered

- The real components, the real global CSS (`club-engine.css`,
  `animations.css`, `metallic-popups.css`, `reducedMotion.css`) and each host
  page's stylesheet, under Vite, headless Chromium (`/opt/pw-browsers`), at
  **393px** (device scale 2) and **1440px**. The club membership limit state
  was also checked at 375px.
- Synthetic props and fixtures only. `supabase.from` / `rpc` / auth and the
  bus were stubbed in the harness; the capability registry answered
  `deployed` / available for every id so gated controls render. No network,
  no production data.
- **Font caveat.** The container has no network and neither Inter nor Roboto
  Condensed installed. The harness mapped them with `@font-face local()` to
  DejaVu Sans (wider than Inter) and TeX Gyre Heros Condensed. Overflow found
  with the wider face was re-checked by measuring layout boxes, not only by
  eye; a surface that only passes because of a narrower font would still pass
  here.
- The felt (surface 1a) is a fragment: `TablePage.css` + `SeatSlot.css` in the
  page's real nesting (`.table-page > .table-container > .table-scaler`),
  the real `SeatSlot` and `CommunityCards` components, and the kill pill and
  masthead line markup copied from `TablePage.tsx`. The rest are the
  components themselves. The union schedule card (3b) is the card markup from
  `UnionDetailPage.tsx` with its CSS module and the real `describeSchedule`.
- Screenshots live outside the repo in
  `/tmp/claude-0/-home-claude/55056245-d628-5d17-bb31-8231b39f1afa/scratchpad/visual-acceptance/`
  as `<surface>-<width>.png`; a fixed surface also has
  `<surface>-before-<width>.png`.
