# Phase 12: remaining enabled variants, first round

This implementation follows the eight gates in `horse-brain-round1-playbook.md`. It is a complete bounded core for Short Deck, Crazy Pineapple, Fixed Limit Hold'em and Fixed Limit Omaha Eight-or-Better. Final integrated verification, frozen replay, performance, engine publication and natural receipts remain separate open gates. All four packs default to shadow; no strength promotion or live candidate activation is authorized by this implementation.

## Domain and owners

The actual engine and cash creator contain nine games. NLH retains Phases 4–8; PLO4 retains Phase 10; PLO5/PLO6/PLO8 retain Phase 11. Phase 12 owns the other four. The tournament catalog contains eight games and excludes Pineapple. Spin accepts only NLH/PLO4/PLO5/PLO6. Tests reconcile the real engine, product catalog and database guard rather than assuming every game name is available in every format.

## Calculation and live path

Each versioned pack supplies its own structural hand quality and entry thresholds. Short Deck connectivity/suits use their own scale. Pineapple uses the three-card structure before discarding and its retained pair afterward. FLH uses its fixed-limit entry scale. FLO8 separately values nut suits, A2/A3 and backup lows, duplication, high strength, quarter/sixth exposure, counterfeit transitions and high/low combined pot shares. These are labeled heuristic baselines, not solver frequencies or equity quantiles.

The bounded sampler uses one physical deck, a separate local random stream, exact game-specific scoring, and a declared sequential public-line prior with at most three attempts per opponent and a uniform escape. Folded dealt seats consume their full original deal. Pineapple opponents choose their retained pair using a declared flop-only structural prior; turn/river cards cannot choose their discard. This prior is distinct from the real player's existing 400-iteration discard chooser. No opponent private cards or discarded cards are read.

Actual Pineapple discard choices continue through the existing worker and `HandController`. The chooser excludes the discarded third card from every candidate pair's samples. The controller now retains each player's own discard in a private per-hand map, returns cloned values only for that player's decision copy, and never stores this knowledge on public seats. The worker requires the authoritative discard action plus exactly one valid, noncolliding known discard on later Pineapple streets. Both ordinary and multiboard baseline equity calls receive that private dead card. Invalid/fractional discard indexes cannot splice a card; rejected and repeated choices leave private knowledge unchanged.

`HorseLogic` calls the four shadow policies after canonical legalization. Fixed-limit bets use the actual street increment, wager cap, reopening and short-all-in menu supplied by `HandController`; no pot-limit size is used. Sampled calls use net eligible pots and separate high/low shares. Tournament proposals reach the existing Phase 7 action-utility owner, including its safety ceilings and unavailable behavior. There is no second ICM implementation. The live worker rejects candidate activation and offline evidence clocks. `ServerTableEngineTurns` records intended/coerced/fallback/not-executed outcomes and retires stale fast/deep receipts. Aggregate and per-variant reasons, eligibility, firing, utility ownership and latency are registered in the data ledger.

## Independent and reproducible evidence

The independent reference checks all 376,992 physical five-card Short Deck hands against both production scorers, including ties and ordering. Another 384 cases construct refunds, contribution layers, eligibility, ranking and integer/cent awards independently for all four games before comparing the actual controller and settlement engine. Eight exact terminal goldens contrast flush/full-house rankings, the Short Deck wheel, Pineapple retained-card wins/losses, board-playing ties, FLO8 quarters and no-low scoops. These known-card answers do not imply certainty about unknown live ranges.

Preflop certification spans every declared seat/position pair, common core depth, action role, rake/ante overlay and supported straddle setting; it checks continuity and monotonic policy selection. Postflop certification contains 19,740 geometry rows (5,880 Short Deck, 2,640 Pineapple, 5,880 FLH, 5,340 FLO8), with all four postflop roles and short/deep boundary states. Separate full-sampler, worker, private-state, utility, execution and hostile-input tests verify behavior rather than only labels.

The fixed league declares 23 populations and three seeds before outcomes, including current six-seat geometry, legacy cash ceilings, tournament ceilings, short/deep stacks and opponent styles. Paired hands use the actual `HandController`, identical decks/seating, complete relative-position rotation, real discard choices, legal actions and chip/rake conservation. The offline controller's existing animation-clock bridge advances a completed discard beat; live cadence is unchanged. A hand has a 256-action bound for the fixed-limit wide-table domain. The command `horse:remaining-variants-evaluate` pins the governor before imports, fingerprints server source/lockfile, records actual work and every result, refuses to overwrite evidence, and fails incomplete/illegal/nonconserved runs. Baseline iterations are the actual variant defaults; the Phase 12 sampler requests 32 samples. Tournament net chips are not tournament prize EV. All losses and uncertainty must remain in the final report.
