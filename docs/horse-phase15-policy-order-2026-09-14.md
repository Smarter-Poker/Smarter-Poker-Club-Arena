# Executable outer Horse policy order

`HorseLogic.decideInternal` now executes its existing outer owners through one decision-local `HorsePolicyGraph`: reference, canonical reference legality, variant policy, Phase 7 tournament utility, tournament continuation, variant utility reconciliation, joint policy and timing. A node cannot run before its predecessor, consume a different predecessor action, run recursively, or continue after an owner throws. Completion requires all eight nodes, and the timing owner cannot change the selected action.

The graph calls the actual production owners. The existing strategy calculations, legalizer, Phase 7 arbitration, protected continuation guard and shadow/candidate restrictions remain inside those owners. The change does not activate an adaptive or candidate policy. A bounded receipt records each node's before/after sampled action, whether it changed, and its elapsed time. These are sampled actions, not invented probability distributions. No cards, player identity, private state or RNG seed enter this trace. The worker transports it with its existing `HorseDecision` result.

## Frozen verification

The pre-refactor source is `79eeba792af39ef2449ec832d25a4f36fa53dfb2`. Its deterministic corpus covers 510 cases over nine variants, cash/tournament modes, preflop/flop/turn/river, one/two/three boards and off/shadow/candidate policies. Unsupported Pineapple tournaments are excluded explicitly. Every existing receipt, action, amount, think time and ending RNG state matches the pre-refactor output byte for byte after removing the newly added trace. Both output digests are `f3428cd115da7b0e73a185f6a4bb5b298129eaa2f0203579d0a343b10eaf2cf8`. This corpus freezes the work clock and governor; it is reproducibility evidence, not latency evidence.

An independent real-clock overhead comparison alternates before/after order for each repetition over 36 one-board cash reference cases, with 20 warmups and 100 measured decisions per case per version. All other phase policies are off and the governor is pinned at one. All 4,320 paired decisions, including warmups, retain the same action, amount, think time and ending RNG. Across 3,600 measured decisions per version, median latency changes from 0.3460 to 0.3484 ms, p95 from 3.1323 to 3.1390 ms and p99 from 3.3353 to 3.3370 ms. These results measure this outer-order overhead; they do not qualify Phase 8's supported-domain budget or strength.

The focused graph, joint-policy and tournament-utility suite passes 81 tests. The TypeScript build passes. The integrated server suite passes 12,069 tests, with 145 declared skips, across 808 passing files and one skipped file. Graph tests exercise ordering, predecessor continuity, immutable action snapshots, failed owners, final-action reconciliation, invalid timing changes and actual decisions for all nine variants. Existing protected-continuation and tournament-utility tests remain part of these checks.

## Remaining Phase 15 work

This is the executable outer order, not the complete first-round Phase 15 graph or ledger. Reference internals still combine authored persona, chart/reference and heuristic/exploit calculations. Their full distributions, bounded modification provenance and internal component timing still need explicit ownership. Canonical state validation remains with the existing worker and final sizing/execution remains with the authoritative table executor. A complete state-bound decision ledger, durable executor reconciliation, replay across restart, frequency/OOD and fleet/reference certification remain open. This trace alone is neither causal evidence nor authoritative execution proof. Protected publication and natural use must be recorded separately.
