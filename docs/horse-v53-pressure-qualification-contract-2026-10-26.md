## Scope and base policy

Compare exactly one hero's current V53-on decision with the same current decision path's `v53Pressure:false`, holding every other setting identical. The maintained worker admission path, source/selection identity and memory snapshot are part of the base identity. An implicit HorseLogic call with selected phases forced off cannot be labeled the current full-tier brain. If selected phases make the pressure contrast inert, the result is recorded as inert, with the reached authority and final-action traces; they are not disabled to create a favorable experiment.

The opponent population is explicitly `v53_pressure_stress_v1`, a heuristic adversarial workload, not a calibrated human market or a claim of absolute profitability. Its PLO action rule follows the existing controlled public aggressive-opponent fixture. The NLH adaptation uses its own legal hole-card percentile and evaluator; it is explicitly heuristic. Every non-hero seat uses this pressure policy, never another seat's cards. A fixed 48-hand public warm history is generated once per variant/dealt count using actual local HandController hands and this declared scripted model on the separately frozen warm-history seed 24307777, disjoint from all main development and reserved held-out seeds; there is no adaptive warm-seed search. It contains no cards or counter snapshots. The observer really participated in those local simulations; none is called a production hand. The immutable records use stable actor UUIDs, a distinct offline table and a declared cutoff of October 25 at 23:00 UTC, earlier than the new experiment's October 26 decision clocks. Original makeOwnPublicHistoryPacket validation and the worker's normal internal observer hydrate the history. No direct counter initialization, observer-view bypass or runtime authority hash change is allowed. Each physical arm retains its runtime through all accepted decisions/commits, while independent paired hands start from the same warm state. This makes the paired distribution conditional on fixed public history rather than treating correlated online-learning hands as independent samples.

Tables use the engine's published 1/2 rake, player-count cap ladder and BBJ drop. Decks, hero seat, button, opponent rules, styles, read state and decision random streams are paired. Every accepted action and settlement goes through the maintained HandController runner. Illegal actions, settlement/reference/deduction/card/conservation/replay mismatches, truncation or differing base digests refuse a result.
