# tests/a-bust-is-ranked-by-when-it-happened.law.test.ts

A tournament bust is recorded with the time it happened: the knockout door stamps `eliminated_at` from the commit of the accepted hand that took the stack (one microsecond apart per rank in a shared hand, smaller starting stack first), never from the moment it accepted the bust. The standings normalizer re-prices every place it moves with the place prepare's own ladder rule in the same write, and refuses rather than re-price once money has moved. A pending knockout generation is resolved as bought back only on a posted wallet-to-pool `rebuy` leg written between it and the player's next generation; anything unproven is refused as before. The engine orders a bust by the latest generation, the one the door binds. The PostgreSQL 17 probe must fail every FIXED scenario on the captured live bodies and pass them all after the migration.
