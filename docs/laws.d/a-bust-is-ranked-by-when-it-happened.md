# tests/a-bust-is-ranked-by-when-it-happened.law.test.ts

A finishing place is decided by when the bust happened: the commit time of the accepted hand that took the stack, busts in one hand ranked smaller hand-start stack first, then user id. The engine's cash-ladder finish (`fn_settle_tournament_places`) ranks every eliminated row by that bust time, derived from the knockout generation the door consumed and its hand commit - timed by the hand's first generation capture when the hand-history prune has deleted the commit, never by the recording order - falling back to `eliminated_at` and refusing a row with neither; it uses the same order to decide whether anything moves, never relabels a place that carries money, and keeps `elimination_sequence` as the witness of the last elimination. Both knockout doors stamp `eliminated_at` with the bust hand, refuse a bust they cannot prove (including a generation the player played on from after a rebuy), and resolve an older pending generation as bought back only on a posted wallet-to-pool `rebuy` leg written between it and the next generation - at the bounty door only once that generation's head was collected (its own obligation exists and every obligation naming it is settled and complete). A refusal that cannot clear by itself (played on after a rebuy; an unresolved generation chain) writes one critical `financial_alerts` row per player while one is open. The standings normalizer re-prices every place it moves and is held only by place money. The unfinished-finish alarm counts from when the last bust was recorded. Satellites and final-table deals keep their own recording-order authorities, and the migration says so. The engine binds the latest generation, refuses a truncated read, and treats the place it hands out in hand order as provisional. The PostgreSQL 17 probe must fail every FIXED scenario on the captured live bodies and pass them all after the migration, applied twice; the reviewed rollback must restore every live body byte for byte, and the migration must apply again after it.
