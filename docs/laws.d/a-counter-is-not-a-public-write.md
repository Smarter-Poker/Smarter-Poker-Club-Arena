# tests/a-counter-is-not-a-public-write.law.test.ts

No browser role can call the raw reel and post counters: the browser adds exactly one view or one share for `auth.uid()`, once a day per content, through `fn_count_content_engagement`; a venue claim (verification code included) is unreadable from a browser, a page claim is readable only by its claimant, venue schedules and legacy tables are written only by the server, a player cannot set their own `email_verified`, `phone_verified`, `access_tier`, `tier`, `skill_tier` or `level`, a log row names its caller, and `club_members`' CHECK is executable by the role that writes the table. Each was a live finding on 2026-10-02; the harness reproduces it as the browser role, runs the migration verbatim and proves it closed.
