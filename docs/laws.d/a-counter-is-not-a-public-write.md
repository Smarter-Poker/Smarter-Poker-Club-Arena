# tests/a-counter-is-not-a-public-write.law.test.ts

No browser role can use the reel and post counters as raw writers: a browser adds exactly one view or one share for `auth.uid()`, once a day per content, through `fn_count_content_engagement` (the old counter names route a browser there, see `a-stale-tab-counts-through-the-same-door`); a venue claim (verification code included) is unreadable from a browser, a page claim is readable only by its claimant, venue schedules and legacy tables are written only by the server, a player cannot set their own `email_verified`, `phone_verified`, `access_tier`, `tier`, `skill_tier` or `level`, a log row names its caller, and `club_members`' CHECK is executable by the role that writes the table. Each was a live finding on 2026-10-02; the harness reproduces it as the browser role, runs the migration verbatim and proves it closed.
