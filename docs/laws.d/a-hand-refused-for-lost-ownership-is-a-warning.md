# tests/a-hand-refused-for-lost-ownership-is-a-warning.law.test.ts

A hand refused for lost ownership is a warning, not a critical (2026-10-02): when the engine cannot prove it still owns a table it refuses its own hand commit before writing anything ("atomic hand commit refused (lease_proof_expired)" or "(hand_lease_stale)"), and runStep re-reports that refusal as postHandTasks.hand_history_failed. fn_ca_financial_alert_to_incident now files exactly that source with exactly those two reasons as a warning drift incident instead of a critical one; it still opens, still notifies, and stays an open unknown until the alert closes on its receipt, so an unrecovered hand still holds the launch gate. Every other post-hand failure and every other refusal reason keeps the moves_chips branch. 812 of 812 such alerts since 2026-10-01 moved no chip.
