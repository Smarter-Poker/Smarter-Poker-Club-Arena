# tests/a-refusal-that-cannot-change-is-not-a-serialization-failure.law.test.ts

PostgREST 14 re-runs any request that raised SQLSTATE 40001 on the same pooled connection until it stops failing, so a refusal that compares an observation with a durable or locked record and raises 40001 pins a pool connection for ever. On 2026-10-06/07 "observed winner ... does not match locked winner <NULL>" did that about 100 times a second for ten and a half hours and starved the 41-connection pool roughly hourly into 504 storms (#6326). The law pins that 20261007071300 moved the twelve disagreement refusals of the terminal, satellite, bubble and cancellation paths to 55000 from md5-pinned bodies, and that no later migration raises a "does not match / disagree / differs / conflicts with" refusal as 40001 or 40P01.
