# tests/a-remote-engine-script-parses-before-it-ships.law.test.ts

Production stayed on the rolled-back engine without the #7290 boot-read fix and the next break paged 104 engine kills. #7304 fixed the comment and pins the drill workflow's own scripts; this law runs `bash -n` on every `<<'REMOTE'` heredoc in EVERY workflow - the release lane (auto-deploy-hetzner) and the crash drill (engine-drill) use the same transport - so a remote script that cannot be parsed fails CI instead of stranding a release or a drill mid-flight.
