# tests/a-removed-identity-leaves-no-accounting-thread-behind.law.test.ts

`cleanup_reserved_certification_account` deletes each accounting conversation it unmaps in the same statement as the mapping. If it left them, the sender ended up alone in a one-member, unmapped "Accounting" thread, which Messenger lists under the club's Messages tab. Six such threads built up in Deep Stack Society's Messages tab between 2026-09-26 and 2026-10-03.
