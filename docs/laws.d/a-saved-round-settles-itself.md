# tests/a-saved-round-settles-itself.law.test.ts

No Diamond Spins game may make a player check or recover a round by hand (owner ruling 2026-09-21, after a Donkey Cross round sat on "Check Your Saved Round Before Starting Another" with every exit held): a saved wager replays itself (useAutoSettle), a ticket the server refused is re-dealt and the wager sent again, the wheel recovers an unconfirmed spin itself, a failed award read, game load, entry quote or ticket deal retries itself and never tells the player to refresh or retry, a won game waits on screen for the player's own Play Game (owner ruling 2026-09-21, R1 and R9, which superseded the auto-start clause: no countdown presses Start on any award page) while the bonus guard never holds a player on an award the page cannot start, and the server keeps a player's live tickets and refuses a dead one before the entry whose foreign key would otherwise turn it into an exception (migration 20260921185541). A ticket-gone restart re-sends the exact refused wager on the fresh ticket (never a request rebuilt from what the page shows), and any other refusal re-reads the award and lets the player go until the server's own blockers change (useRefusedAward). Both start functions answer a ticket this request already used with its receipt before they can call the ticket gone (reversed, a replay would be answered gone and the wager sent again: a second charge). An error the database answered is an answer (DiamondBonusService, the same rule as the wheel): a SQLSTATE means that execution rolled back, so the saved wager is cleared and refused (a passing 40001, 40P01, 55P03, 57014 or PGRST000-003 after three sends of the same request) and the page lets the player go; only an error with no code keeps it replaying, never from a background tab; a receipt the browser cannot verify stops after three, releases the guard, re-reads the game and keeps the wager for the next visit; a wager that could not be saved was never sent and is refused; and Crash replays nothing behind its load-error screen.
