# tests/an-owed-engine-release-is-offered-until-production-holds-it.law.test.ts

While the live engine's releaseSha does not contain the newest engine-affecting commit on protected main, every protected-main push offers that commit again through the one receiver (`deploy-club-arena-engine` -> `auto-deploy-hetzner.yml`), never while a receiver for the same SHA is still running and never twice within OFFER_INTERVAL_SECONDS (50 minutes), so a refused release is offered once per maintenance window until it lands instead of waiting for the next engine push. An unreadable or foreign live identity is UNKNOWN and offers nothing on that basis; an unreadable run list fails the step. Negative proof: run against the pre-change `stage-engine-release.yml` (origin/main 0c6bda56d5), 11 of 13 cases fail, including the behind-main fixture, which that detector answers `release_required=false`.
