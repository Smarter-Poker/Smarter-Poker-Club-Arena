# tests/engine-drills-ride-the-release-lane.law.test.ts

A live engine drill (DA08 crash failover, DA10 rollback then roll-forward) runs only through `.github/workflows/engine-drill.yml`, a default-branch repository event that binds the drill to one run key and hands it to the unchanged durable Hetzner release transaction. The law pins the event-only triggers and single drill lane, the strict production-door check for every drill target, that drills never write deploy receipts, that the transaction takes its drill mode only from the root-owned record bound to the run key, prepares the seal's audited rollback mode only for a rollback, crashes the engine only past the locked restart certificate and rollback readiness with recovery armed before the kill, never spends the off-cycle window or makes a release stand aside, and admits an older target only above both compatibility floors and only if this host already sealed it. It executes the real drill shell in `tests/operations/engine-drill-admission.py`.
