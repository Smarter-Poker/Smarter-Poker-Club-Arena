# server/src/engine/aDetectorMayNotCryWolf.law.test.ts

A financial alert fires where a condition is real, not on the first attempt of a retry that always clears; an error report never renders a rejection as "[object Object]"; and the tournament balancer re-checks the hand boundary immediately before vacating a source seat, so a dealt hand is never discarded for everyone at the table. The stats pipeline is held to the same rule from the other end: ClubArenaStatsTriggerGap raises on a SHARE against a sample floor rather than a bare non-zero count, needs several consecutive breaching reads to raise and several clean ones to clear (so the 15-minute ca_roll_hand_stats_forward compensator cannot drive a 60-second alarm the way it did 32 times on 2026-09-11), treats a window it cannot answer as UNKNOWN rather than healthy, and never sends the reader to a Postgres log line that the atomic-commit path cannot produce.
