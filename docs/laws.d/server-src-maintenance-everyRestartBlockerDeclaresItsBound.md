# server/src/maintenance/everyRestartBlockerDeclaresItsBound.law.test.ts

Every reason the restart census can report must declare its bound in `MaintenanceBreak.UNPARKED_REASON_BOUNDS`, so an unbounded "not yet" that is really "never" (CLAUDE.md 10.86 rule 1; the shape of `f06_preparation_unresolved`, the retained-preparation loop and `stopped_bank_custody_unconfirmed`) fails CI before it can wedge a release. The reasons are derived from the code, not listed: every `count(...)` and fallback literal in `unparkedTables()` and every literal an engine's `maintenanceDurabilityReason()` returns. A reason asked of a non-running engine must be scope `lifetime` with a finite bound, a distinct never-name and an explicit `neverHoldsGate`; each lifetime reason is driven past its bound and must report its never-name with exactly the declared verdict; every declared name is zero-seeded on /metrics; no bank or custody name may enter the release allow-list. Negative proofs plant an unbounded reason above the running skip, an undeclared engine reason, and a lifetime declaration without a finite bound or distinct never, and require all three to be reported.
