# server/src/services/supabase/theUnionRakeLegIsWrittenOnce.law.test.ts

The legacy rake helper calls one authoritative cash transaction with club, table, hand number, optional history ID and separately priced BBJ amount. It cannot split counter, union wallet and journal requests. The transaction retains union rake and burns standalone rake. A failed request is reported and propagated so the caller can retry the same identity. Native PostgreSQL coverage in scripts/dev/probe-standalone-rake-burn-pg17.py verifies union balance/journal parity, standalone supply retirement, journal/register rollback, historical receipts and concurrent replay.
