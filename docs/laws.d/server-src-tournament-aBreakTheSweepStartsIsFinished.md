# server/src/tournament/aBreakTheSweepStartsIsFinished.law.test.ts

A Break The Sweep Starts Is Finished: on 2026-09-29 the $100 Freerolls 87a68e55
and cb8f2dd1 held seven and five open table breaks while 33 and 37 tables sat
with one player, because every step of a break visit answered to the sweep's
five-second work budget, a visit stopped wherever the clock ran out (after the
custody claim, inside the destination read) and the next admission's
discovery had already moved the server cursor on to the next operation. With
the real TournamentManager and TournamentRetirementCustody this pins that
discovering one operation and visiting it is one unit that the budget cannot
cut (manager stop and sweep abort still can), that further operations are
visited in the same admission only while budget remains and each at most once
per pass, that a new generation's cursor conflict is answered with the adopted
revision in the same pass, that a close_confirmed break held by a dead
generation is claimed, acknowledged and released by the live one, and that a
break left open names why.
