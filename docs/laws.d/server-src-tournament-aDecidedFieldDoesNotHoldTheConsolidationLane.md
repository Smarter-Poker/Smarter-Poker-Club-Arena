# server/src/tournament/aDecidedFieldDoesNotHoldTheConsolidationLane.law.test.ts

A decided field (one table, at most one stack with chips) is served from the scheduler's decided lane even when it is also marked consolidating, so a field with real consolidation work (a table break to claim, a held satellite qualifier boundary) reaches the one consolidation slot at once, however many decided games are waiting.
