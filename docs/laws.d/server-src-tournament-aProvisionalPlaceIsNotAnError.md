# server/src/tournament/aProvisionalPlaceIsNotAnError.law.test.ts

When the finishing ladder runs out downward (places handed out while late registration grew the field), the sweep still places the busted player at the lowest free place above the seed and logs it, without an error report, because the finish derives every place again from when each bust happened before anything is paid; a ladder with no free place at all is still reported as critical. A break retirement that throws a custody staleness error after the sweep's work budget expired is logged as the designed yield; the same error with budget left, and every other sweep failure, is still reported as Tournament.elimination_check_error.
