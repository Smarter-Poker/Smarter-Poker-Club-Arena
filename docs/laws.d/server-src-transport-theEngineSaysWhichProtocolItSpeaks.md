# server/src/transport/theEngineSaysWhichProtocolItSpeaks.law.test.ts

The engine says which protocol it speaks (Realtime Phase 4, 2026-09-05): the origin keeps old assets deliberately (CLAUDE.md 1.1), so a tab open since yesterday is running yesterday's bundle against today's engine mid-hand - a feature, and precisely why the engine must be able to say "not that old". Every socket URL now carries `?v=` from ONE builder covering all three (`/ws/multi`, `/ws/table/:id`, `/ws/channel`), because a version on two of three would refuse the stale bundles that happened to be muxed and silently serve the rest; a version below `MIN_CLIENT_PROTOCOL` is refused with close 4426 after completing the handshake, never a pre-handshake HTTP status, which reaches a browser as 1006 and means "retry" - the one thing a stale bundle must not do, and the 2026-09-03 lesson applied before it costs anything; the parser reads absent, malformed and negative all as 0 and never NaN, since a comparison against NaN is false and would let garbage through the one gate meant to catch it; the gate is a deliberate no-op at 0 today, installed so the day a frame changes shape there is somewhere to put the number; and the client answers 4426 with the shared hard reload that drops the service worker and purges Cache Storage, not a plain reload that re-serves the same stale document.
