Trust is renewed, and bounded (Realtime Phase 5, 2026-09-06): a socket was authenticated once at the upgrade and then trusted for as long as it stayed open, which is the 2026-09-03 outage from the other side - that fix stopped a revoked session OPENING a socket and said nothing about the sockets already open, so with a seven-day token and a tab left open a player who signed out keeps playing at a real table with real chips. Every live socket is now re-checked on a five-minute period from the heartbeat sweep, staggered per socket and bounded per sweep so the mechanism protecting the platform cannot become a thundering herd against auth, with the next slot claimed BEFORE the await so a slow GoTrue cannot re-queue one socket every sweep; only a DEFINITIVE rejection closes it, because treating "could not ask" as a refusal would sign every player out the moment auth had a bad minute. A per-user socket cap refuses the ARRIVING socket with 4429 rather than evicting an existing one that may be carrying a hand, checked before the connection is registered on both upgrade paths, and generous enough that normal play never meets it. Both refusals are counters on the always-on exposition, because a refusal nobody can see is how twenty-two hours went by.
