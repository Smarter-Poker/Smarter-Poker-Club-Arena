# tests/an-abandoned-first-hand-of-an-event-that-never-dealt-is-a-misdeal.law.test.ts

The abandoned-generation door voids a dead generation's dealt-but-unsnapshotted FIRST hand of an event as a misdeal when no hand was ever committed at any of the event's tables and every chair holds exactly the event's starting chips; every other table is still proved against its last committed hand, every other refusal is unchanged, and no money moves.
