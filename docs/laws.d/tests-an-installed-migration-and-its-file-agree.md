# tests/an-installed-migration-and-its-file-agree.law.test.ts

An installed migration must have a file in this repository, and a merged migration must be installed or explicitly marked superseded. On 2026-09-27, 1,272 installed migrations had no file here, because both directions were only ever asked on a schedule. This law pins the apply-time alias and pinned-file superseded registry as claims that must hold in the tree (`scripts/ci/migration-aliases.mjs`), the three name shapes the installed-has-a-file check used to miss, the 24-hour grace that lets work in flight pass without letting a gap age, the `-- SUPERSEDED BY <version>` marker honoured only when the named file exists, and the shape of `.github/workflows/migration-ledger-reconciled.yml`: both questions on every pull request into main and every push to main, from trusted default-branch code only, never on a timer.
