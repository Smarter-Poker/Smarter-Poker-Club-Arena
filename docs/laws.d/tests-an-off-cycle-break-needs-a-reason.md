# tests/an-off-cycle-break-needs-a-reason.law.test.ts

An engine release asks for an off-cycle "Deployment Recovery" window only with a reason (an urgent commit trailer, a degraded or wedged serving engine, no scheduled break before its own deadline, a scheduled break it was waiting for that shipped nothing, or the seal's unshipped failed ancestor), never while a release of a newer engine SHA is live on the host, and the seal grants at most one per rolling hour across every release; the policy changes only when a release asks for a break, never the certificate, the admission ladder, the rollback reserve or the locked read, and a release that waits for the scheduled break always has at least one whole hour of them before its certificate deadline.
