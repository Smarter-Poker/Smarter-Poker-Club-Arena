# server/src/benchmark/TheChartMatchesTheDeck.law.test.ts

V46's hand-class chart is published PLO/short-deck theory and there is still no solver export in the estate - but the engine's own equity evaluator is a reference the chart had never been checked against. `measureHandClassEquity` deals many hands of each class over the real deck of the real variant and reports mean all-in equity at 2, 3 and 6 handed. The law asserts only what equity can honestly adjudicate: the worst class in the deck must be one the chart folds always (`trips`, .1010 six-handed against a next-worst of .1492), everything folded must be below the field average, the premium classes must out-equity the marginal ones, and the sampler must still find every class the classifier can emit. It deliberately does NOT pin a strict equity order - a rundown has poor all-in equity and is one of the best hands in the game, and encoding that order would make the brain worse.
