# tests/the-daily-login-streak-counts-consecutive-days.law.test.ts

The daily login reward is 10 on day one and 5 more for every consecutive day, to 110. From 2026-09-07 `award_diamonds_v2` counted the run with `v_today - rn` (date minus bigint, which does not exist) inside an `EXCEPTION WHEN others THEN v_streak := 0` that hid the error, so every login paid 10. The law pins the `v_today - rn::int` count, keeps any exception handler out of the daily_login branch, keeps the 10/5/110 rule and the player's-own-login-days source, and pins the one-time back-pay in migration 20261019092327: derived from the rows the function reads, checked against the streaks the function recorded, paid once per player through `add_diamonds_to_balance` under `daily_login_streak_backpay:<player>`, never by a job, and never filtering horses.
