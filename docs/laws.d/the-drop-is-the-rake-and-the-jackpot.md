# server/src/services/TheDropIsTheRakeAndTheJackpot.law.test.ts

The fleet plays itself, so its aggregate result is zero minus what the house takes: `sum(net_bb) + sum(rake_bb) + sum(bbj_bb) == 0`. Measured 2026-09-06 over 11,687 cash hands and 31,186 horse seat-hands: net -10,797bb, attributed rake +9,020bb (99.1% of the 9,103bb taken), residual -1,778bb, table bad-beat-jackpot drop 1,761bb - a 1.0% match, so the fleet's true result is 0.0 bb/100 rather than -34.5. `ServerTableEngineSettlement` sends `bbjAmount` through `logHandHistory` to `HorseHandReview`, which allocates it with `allocateWeightedShareCents` over the SAME contributions list as the rake; `horse_daily_nets.bbj_bb` carries it; `RegressionContext.bbjBB100` and `fleetQuartile` both judge net + rake + jackpot, and each half is independently optional so an older row is unchanged. `fn_audit_fleet_drop_identity` asserts the identity nightly from `horse_daily_nets` alone (its first cut scanned a day of `hand_history` and timed out - see migration 20260906022655) and is reported inside `fn_audit_tuner_health`, because a short attribution makes every verdict there a symptom rather than a fact.
