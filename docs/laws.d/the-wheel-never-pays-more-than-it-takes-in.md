# tests/the-wheel-never-pays-more-than-it-takes-in.law.test.ts

The Diamond Wheel (Dan 2026-09-07: 80 percent return, 20 percent house edge, "never pay more out than we take in"; 1 diamond = $0.01, 1 chip = $1.00) keeps its promise by arithmetic: only a prize table that returns exactly 0.800000 on 100,000 weight can be activated; a chip tier is drawn only when chips_paid + prize <= chips_minted + this spin's mint + the host's exposure allowance and the host bank holds it, a diamond tier only when the diamond float covers it; the chip share of every spin is a declared, registered issuance to the host, the diamond share accrues to the float, the rest is retired diamonds; and the rate is one row, ca_bridge_rate, read by fn_ca_bridge_rate() and never a literal in the wheel or the owner bridge.
