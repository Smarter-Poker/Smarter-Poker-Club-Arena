# tests/the-wheel-runs-the-way-the-other-two-do.law.test.ts

The Diamond Wheel's Auto Spin is the same runner Plinko's Auto Drop and Crash's Auto Play already use, not a second one: all three call autoRunVerdict, which makes exactly one decision (wait, press, finish, or stop because the page would refuse a thumb) and decides nothing about an outcome, and the wheel's runner presses handleSpin rather than reaching for the service itself, so there is one path that moves money. The run stops wherever a thumb would be stopped: on any blocker the page would print, on a refusal from the server, and on a request that never answered, and while it runs the run plate is the stop plate in red. Two rules are the wheel's alone. A welcome spin is never auto-played, because it is once per member ever and costs nothing: the size cannot be cycled and a run cannot be started while the wheel is on the house, the primary plate stays a single welcome spin, and the Odds plate keeps the run plate's seat on the one screen where a run is meaningless. And the wheel turns before a spin is counted: its result is decided at the server and then spun for five seconds, so busy covers the animation as well as the request, the spin is counted when it lands rather than when it is asked for, and the pause between spins is the wheel's own, longer than Plinko's and shorter than Crash's. Moved 2026-09-21 (owner ruling, R18): the wheel's run accumulates. A landed spin is tallied (its prize or bonus game recorded on the run) rather than merely counted, a refusal ends the run with the server's own reason, the run is declared to and closed at the server (fn_wheel_run_begin / fn_wheel_run_end) so a refresh finds it, and the wheel's plate offers 5, 10 and 25 only.
