# Table Management Four-Bay Command Rail V1

One continuous 2172 by 724 RGBA production chassis for the four Table Management creation commands.

Generated with the built-in image generation workflow from the approved `SpadeConsole` club head and two-plate foot references. The source prompt required four equal empty bays, blackened machined steel, thin chrome, restrained electric-blue light, no text, no icons, no logos, and genuine transparency outside the object. Live labels and hit targets are printed by `GameCreationActions`.

Do not crop a bay out, repeat it, recolor it, or place another frame behind it. Replace the complete master with a versioned sibling if the rail is redesigned.
