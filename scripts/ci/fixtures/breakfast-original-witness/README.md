# Original Breakfast witness qualification

This finite fixture preserves the September 8 Breakfast event's actual recorded
32 finishing positions, first failed rank-21 request, four existing paid prizes,
and the unanimous original five-place payout contract. It is replayed only in
an empty, private PostgreSQL 17 database owned by the maintained MTT Execution
harness. No production connection argument is accepted.

The archived request is evidence of original rank intent and failure. It is not
an atomic hand result, knockout candidate, payout, or a historical committed
elimination. The new source creates a distinct immutable admission receipt and
lets the existing cash/terminal authorities produce any new result now.

The actual retained case has two unresolved limitations: the survivor carries
430,255 chips against 408,000 starting entitlement, and the $17 of original fee
charges lacks contemporaneous earning terms. The fixture preserves those chips;
no rebasing or invented issue transaction is allowed. The exact prerequisite
version 3 terminal keeps the 17 original fees in escrow with an immutable
unresolved obligation. Player results can be final while accounting remains
incomplete. This fixture introduces no synthetic earning agreements or bank
credit, and a changed original source must still refuse the whole transaction.

Three unfinished September 8 snapshots on closed tables are historical evidence,
not current hand ownership. Their entire rows remain unchanged. The live table
must still have no hand/permit/candidate/lease, and the current manager identity
is supplied by a fresh read rather than inferred absent.

`case.json` retains the original roster and financial evidence. `physical.json`,
`conflicts.json`, `installed-terminal.json`, `terminal-schema.json`, and
`ledger.json` retain bounded contemporaneous observations with their original
archive source hashes. The generator binds the exact captured financial and
guard function definitions, owners, ACLs, settings and enabled trigger bindings.
It leaves disabled historical guards unchanged.

The separate `qualified-fee-custody-*` captures bind Union's frozen prerequisite
source and original dependency definitions. They do not claim live installation.
`original-fees-lossless.json` preserves its original PostgreSQL text, including
numeric scale inside nested JSON. Ordinary binary-float parsing or formatting
would alter the immutable fee fingerprint even when the amounts compare equal.
Only the Breakfast event from that retained original-fee packet is loaded.

Run only the directly affected native qualifier:

```sh
python3 scripts/ci/test-breakfast-original-witness.py --pg-bin /path/to/pg17/bin --evidence /unique/owned/output
```

The output manifest records every input, command, actual failure, completion
assertion and cleanup. Source qualification is separate from protected source
delivery, migration installation and any production operation owned by MTT.
