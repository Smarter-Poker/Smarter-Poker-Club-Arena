or transaction rows. `actual-catalog.json` records the complete two relation
shapes and four original owner metadata. `actual-indexes.json` retains all
captured competing indexes. The current hand-line reader and complete source65

constraints, loads exact linked/reducer/witness/read and original hand-line

resolution owns the requested Union while the outcome carries another scope.
The start boundary is included and end boundary excluded. All original full
proof/evidence hashes remain evaluated. The actual resolution CHECK constraint
also refuses corrupt proof input.

functional hand-reader execution. The complete captured source65 is then loaded
and its entire definition and metadata are checked unchanged across exact index

performance, 84-window book readiness, payout or deployment is inferred.

its full original four-field row hash with the unchanged function output. The
index test requires natural recognition-window index selection without planner
forcing, full row/reducer/witness parity, actual metadata preservation, generic
and custom results, frozen/ACL refusal, atomic rollback, replay, catalog faults
and an actual failed concurrent index. The local PostgreSQL cluster is stopped
and removed in `finally`; scratch stays on the external SSD locally.
